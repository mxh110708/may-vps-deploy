# May VPS Deploy v0.9.36 发行范围与验证

日期：2026-10-25。整合原计划第十一至十四轮和已完成的监控 M1–M3 支线。本文说明本次发行；各轮记录中的“尚未发布”描述的是当时实现与验收阶段，不能据此把监控支线当作原主线完成依据。

## 功能范围

- [第十一轮](FORWARDED-NODES-ROUND-11-2026-10-23.zh-CN.md)：已验收的 TCP／UDP 转发可投影为客户端节点，保留鉴权、TLS／SNI、稳定来源身份及失效保护，补齐服务重启恢复。
- [第十二轮](TCP-CHAIN-ROUND-12-2026-10-24.zh-CN.md)：三台独立受管实例的有限 IPv4 TCP 前置→中转→落地，统一依赖、端口、来源白名单、逐阶段验收和失败补偿；不包含 UDP 编排、隧道封装或共享实例。
- [第十三轮](INBOUND-MODEL-ROUND-13-2026-10-25.zh-CN.md)：独立入站服务、监听、用户、证书、出站及恢复范围，按用户生成 Clash/Mihomo 与 sing-box 节点；Reality 固定 Xray，AnyTLS／SS2022 固定 sing-box。旧角色服务继续使用原维护入口。
- [第十四轮](HYSTERIA2-ROUND-14-2026-10-25.zh-CN.md)：Hysteria2 部署、启停、移除、用户与证书轮换、带宽／Salamander 设置、显式固定核心更新、真实 QUIC 鉴权及客户端生成。TUIC 与更多服务器出站仅完成评估。
- 监控 M1–M3：限节点、限期的独立只读指标；固定 May Server／Agent 的部署维护；HTTPS 与安装身份比对、指定节点凭据及连续上报验收。配套 [May Monitor Server v0.1.0-rc.3](https://github.com/mxh110708/may-monitor-server/releases/tag/v0.1.0-rc.3) 仍为预发布，Agent／Web 沿用已审查 RC1。旧 Komari 保留，迁移由用户逐节点审阅执行。

本地构建曾报告 NuGet 漏洞元数据源不可达的 NU1900 警告。构建成功和协议验收不等于新一轮完整依赖安全审计。Monitor 配套源码、依赖和默认关闭能力的边界见其审查报告及发行说明。

## 发行与使用

正式安装 EXE、便携 ZIP、应用文件清单、`SHA256SUMS.txt` 和既有 Google BBR v3 对应源码一起发布。打包使用提交后的干净源码，执行秘密扫描、内置核心／内核来源检查和真实 WinUI／.NET 本地运行环境复核。安装包内的组件版本、文件归属清单及更新入口需一致；公开附件以 SHA-256 复核。

此次授权范围为 Deploy 与其必需的配套 Monitor Server 发布；不安装用户应用，不修改运行中的 Route／系统代理／TUN，不连接或变更生产 VPS。新增服务器功能只有在用户选择实例、审阅并执行后才生效。线上托管、配额、计费与未实现协议不包含在此版本中。
