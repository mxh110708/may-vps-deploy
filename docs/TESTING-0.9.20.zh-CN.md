# v0.9.20 跨功能边界修复与回归

日期：2026-10-12 至 2026-10-13。本轮根据全项目审查修复 17 项问题，重点是修改范围、来源身份、恢复预检及实际状态回写。测试使用独立归档；后台窗口没有激活，也没有使用鼠标、切换本机代理或修改非测试 VPS。

## 修复范围

| 审查问题 | 修复行为 |
|---|---|
| 协议维护重建整套防火墙 | 首次部署、追加安装和维护统一为受管表批次。维护前对比归档、文件及运行规则；其他表保留，不重启会清空规则集的 nftables 服务。恢复也核对本轮写入身份。 |
| 基础调优重放旧参数 | 只写入本次选定的 fq、拥塞控制及明确选定的缓冲参数；保留旧文件中其他参数的持久化内容，不在本次任务重放 TFO、MTU 或其他旧值。 |
| 健康检查导致节点来源失效 | 相同明文不重复加密；新方案按每个节点的实际连接和凭据建立来源身份，版本、健康时间及其他组件凭据变动不影响节点。旧方案可迁移，轮换后的节点可明确更新来源。 |
| Shadowsocks 验收绕过可信入口 | 从白名单中匹配已纳管、已启用的入口，两个固定核心均通过该入口连接落地；缺路径明确记未完成，不从本机直接绕过白名单。 |
| 网络恢复覆盖外部改动 | 在写入前记录文件摘要、权限和选定运行值，记录实际队列；恢复前检查全部对象，外部改动保留。缺少写入身份的旧活动恢复点拒绝自动覆盖。 |
| 双文件导出覆盖中途编辑 | 每个目标写入前重新核对摘要与来源；已写入的候选可恢复，外部编辑不覆盖，未确认事务保留。 |
| 删除或重命名节点仍残留在配置 | 跟踪所读取来源中的节点名称，生成明确的删除与重命名集合。更新引用并保留无关节点、规则、DNS 和高级设置；使自定义组变空的操作需要先修正成员。 |
| 新证书改变原证书 DNS 出口 | 出口绑定随 DNS 凭据文件保存，续期按证书分别运行；历史全局绑定迁移到原凭据。重新安装时只更新所选证书的续期凭据路径。 |
| AnyTLS 卸载后无法重新安装 | 校验受管执行器、续期插件、凭据路径、证书目录、证书内容及请求域名后复用遗留 TLS 材料；未知残留或其他域名仍拒绝。 |
| 首次组合部署未验收备用入口 | 临时切换并独立验收每个备用入口，再恢复计划选定状态。备用未完成不会被整体 Passed 隐藏。 |
| 主控恢复仍显示新版本 | 读取恢复脚本返回的实际版本和程序 SHA256，同步计划、当前清单及版本来源；健康检查也同步已核对的监控版本。 |
| 主控恢复混淆启用与运行 | 临时启动用于验证，随后分别恢复开机启用和当前运行状态；主控专用恢复保留 Tunnel。 |
| 历史固定内核无法重新选择 | 已安装包只有与受管历史、包身份及启动文件摘要匹配时才复用；无需再次执行包安装，未知已安装内核仍拒绝。 |
| 健康异常没有显示 | SSH、协议、配置漂移、监控、证书和防火墙检查形成实例页结果。异常结果直接显示，任务为含提示完成；读完不等于健康。 |
| 停用退役虚构 Agent 安装 | 分开维护安装、启用和运行标记；未安装 Agent 不会因停用而变成已安装。 |
| 恢复点选择混入其他范围 | 界面仅列兼容的协议恢复点；本地材料、管理端口、程序/配置兼容性、监听冲突、当前防火墙及远端摘要在建立恢复保护之前核对。 |
| 卸载留下当前凭据和导出 | 清理所选协议的当前凭据、程序记录、服务配置副本和受管客户端片段。历史加密恢复副本及独立导出保留；失败恢复按摘要还原当前归档。 |

## 限制与兼容性

旧的活动网络/防火墙恢复记录如果没有本轮写入身份，不会凭受管标记自动覆盖；保留恢复材料并要求维护者核对。它们不能被标记为已安全恢复。普通已完成归档及同内容凭据文件保持可读。

旧配置方案没有逐节点来源身份时，连接内容相同的节点可迁移，自动名称变化也能匹配。含无法明确识别来源的行时保留原来源核验；需明确更新受管节点，或重新读取已经核对的权威配置，不能自动把过期节点转为无来源的手动节点。

真实高峰与非高峰的长期比较、本机直连 IPv6 仍缺条件；不新增断电、无法启动等已排除极端故障。本轮没有进行 DNS Token 的再次吊销、全新证书签发或历史内核的另一轮实际重启。
