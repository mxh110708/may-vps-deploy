## 使用流程

1. 在「配置设计」添加订阅来源，完成首次预览后保存方案。支持范围仍为纯文本／Base64 分享链接列表；原生 Clash YAML／sing-box JSON 从读取现有配置进入。
2. 保存当前草稿，打开节点页的「来源中心 · 定时与批量同步」。中心发现已保存方案与加密节点组中的来源；不读取其他应用的运行目录。
3. 选择来源及「立即获取（仅更新缓存）」。成功后只写加密缓存，方案、节点组、已导出文件和服务器配置都不会自动改变。
4. 选择「批量差异预览与同步」，勾选要同步的方案和节点组。引用这些节点组的方案也会列出，可以一并选择。
5. 逐项检查新增、删除、改名、参数变化、默认出口与上游引用影响。出现任一冲突时整批确认不可用；先处理冲突再重新预览。
6. 确认后更新选中的本地加密对象。当前打开的方案会重新载入；重新生成、校验并审阅导出客户端配置，原输出文件不会自行更新。

来源 URL 和认证参数只保存在私人加密记录中。来源选择器显示名称与主机名，差异显示节点名称、连接类型、端点和变化类型，不展示密码、UUID 或完整订阅 URL。

## 定时拉取的含义

默认关闭。来源中心选择「配置定时拉取」，明确启用后设置 15–1440 分钟间隔。计时器仅在 Deploy 运行时检查：每分钟判断到期来源，每次最多获取4个，最多启用100个来源。应用退出会取消正在执行的下载，不安装后台服务或计划任务。

计时器更新缓存和变化提示，不自动接受差异。成功获取但没有内容变化时只刷新时间；HTTP 错误、无法完整解析的列表、空列表或错误页面保留上次有效缓存。全部方案／节点组都已移除该来源后，到期检查会关闭其定时策略，避免继续获取无人使用的来源；已有缓存保留供核对。

下载继续使用既有的有界下载器：30秒、512 KiB、至多3次重定向，拒绝 HTTPS 降级。支持跟随系统代理、直连或显式无认证 HTTP／HTTPS／SOCKS5 代理。本机 HTTP 仅用于回环验证，公网地址要求 HTTPS。下载错误不回显带令牌的地址。

相同规范 URL、下载方式及指定代理合并成一个获取身份。同一地址在各方案中的地区、用途、来源 ID 和节点归属仍分别保留；不会因为共用缓存而把所有方案改成同一地区。不同下载方式或代理是不同获取身份。

只保存小型非敏感调度索引，空闲检查不解密全部订阅内容；到期后才读取对应记录。来源下载期间不能迁移私人归档，目录选择／迁移期间暂停此计时器，取消或完成后按现有策略恢复。

## 新增、删除、改名与冲突

| 情形 | 处理 |
| --- | --- |
| 新增连接 | 保留来源与用途；各方案生成稳定的独立节点 ID，重做同一预览不会产生另一批随机身份。 |
| 同一连接在上游改名 | 保留原节点 ID；原显示名未被用户改过时跟随改名，并更新默认值和原生上游引用。 |
| 用户自行改过显示名 | 保留用户显示名，仍记录来源的原名变化。 |
| 来源参数变化、本地未修改 | 显示变化类型后更新完整原生连接；不展示鉴权值。 |
| 本地和上游同时改参数 | 阻止整批应用；先解除关联保留手动节点，或核对并解决本地修改。 |
| 来源删除本地已修改节点 | 不删除，报告冲突。 |
| 删除默认出口／上游 | 显示受影响引用，移除失效引用后要求重新指定；不自动改成 DIRECT。 |
| 节点同时由订阅与节点组管理 | 拒绝重叠归属，先解除其中一种关联。 |
| 组更新但未选择所有引用方案 | 提示未选引用数量；这些方案保留旧快照，须以后同步，旧来源资格不能继续用于导出。 |
| 预览后缓存或保存对象又发生变化 | 拒绝旧预览，重新获取或预览，不覆盖后来编辑。 |

本轮复用既有订阅和节点组的连接参数处理。节点组仍要求包含完整上游依赖，不嵌套节点组；不会用丢弃不支持字段的方式通过同步。

## 本地事务与恢复

确认时固定来源版本和每个对象的前后摘要，取得来源锁与按顺序排列的对象锁，再写加密事务记录。多个文件不是操作系统级原子提交；事务提供中断识别、顺序写入和局部恢复。

取消、某个对象写入失败或最终完成标记写入失败，会核对并恢复本次已写对象。应用被关闭、断电或恢复再次失败时，来源中心提供「恢复未完成的批量同步」。它先核对所有对象仍是事务记录的 Before／After，再恢复任一文件；发现其他编辑时停止，保留材料，不覆盖新数据，不自动重放应用。

未完成事务会阻止相应方案／节点组的保存、删除、配置生成、分享导出及其服务器下一跳／线路消费。只读查看和恢复入口继续可用。未知事务格式拒绝写入。完成或回退后的记录只保留对象与前后摘要，移除重复的完整快照，减少凭据副本和归档增长。

遇到冲突不要删除事务文件来绕过检查。先保留私人归档，核对后来修改属于谁，再从恢复入口处理。不要将私人事务、缓存或方案作为问题附件公开上传。

## 存储与范围

以下路径均相对于应用当前的私人归档根映射，实际位置通过设置页查看：

| 相对路径 | 内容 |
| --- | --- |
| `private/client-source-sync/sources/<id>.dotnet.private.json` | 加密来源定义、最后有效内容、版本、时间与策略。 |
| `private/client-source-sync/schedule.json` | 非敏感调度身份、间隔与上次尝试时间，不含 URL 或节点凭据。 |
| `private/client-source-sync/transactions/<id>.dotnet.private.json` | 加密批量事务；结束后仅保留摘要。 |
| `private/client-schemes/`、`private/client-node-groups/` | 继续使用现有加密方案与节点组格式。 |

本轮不会建立在线订阅托管、用户配额或计费，不自动修改学校网络、系统代理或 TUN，也不因订阅变化自动部署服务器。后台自动获取依赖 Deploy 运行，不能等同于全天候独立同步服务。

## 验证与维护入口

专项入口为 `--source-sync-only`，已纳入 `.NET --group clients`。包括有界下载器的实际回环连接与显式代理、定时缓存不改方案、三方案加节点组联合同步、改名引用、删除、本地冲突、预览变化、取消、写入失败、最终标记失败、中断恢复、外部编辑拒绝及未知事务拒绝。

WinUI 使用既有后台接口 `suite.source-sync`，仅合成归档；验证来源入口、定时策略、四个同步对象、脱敏差异、取消、冲突禁用确认、整批应用与当前草稿刷新。要求零窗口激活、零前台采样，不打开测试窗口。

本机受控下载、模型事务和后台表单证明对应流程，不证明某个真实订阅长期可用或已部署至生产。当前验证汇总见[第二十六轮同批验证](SERVER-RULESETS-ROUND-26-2026-11-01.zh-CN.md#同批验收)。
