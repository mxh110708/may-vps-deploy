# 监控归档与只读状态核对

> 文档定位：旧归档／Komari 实施记录，保留当时的判断与验证范围；不是当前 May Monitor 迁移或安装教程。当前使用见[监控运维](MONITOR-OPERATIONS.zh-CN.md)和[维护手册](MAINTENANCE.zh-CN.md)。


旧命令行实例可能先部署代理，之后才另行安装监控。其部署计划中的 `Komari.Enabled=false` 不能作为监控服务当前未安装的证明。离线转换保存的 `DesktopImport.*LastKnown` 是历史记录，不能直接授权远端升级、卸载或恢复。

实例页将这些组件标为“历史记录待核验”，提供“核对并纳管”。它执行同一个只读健康检查，核对 Agent、主控和 Tunnel 各自的安装、启停、实际程序及受支持布局。完成后更新 `MonitoringInventory` 与桌面维护读取的状态字段，并立即重新显示当前实例。未安装的组件保持不可维护；自定义、不支持的程序布局不会因发现 systemd unit 而获得自动管理权限。

Agent 配置通过 SSH 私人读取通道补齐缺失的连接地址与 Token，Token 和完整配置只写入当前用户保护的加密归档。已有连接地址或 Token 与服务器不同则保留原值并提示漂移，不隐式轮换。核对不完整、过时、配置无法读取或状态矛盾时，保留原组件状态。Controller 和 Tunnel 的既有备份元数据、历史材料和私人凭据保留。

“已核验”表示曾读取对应时间的状态，不保证以后一直在线。管理任务执行前仍重新检查远端状态。健康检查不安装组件、不重启服务、不更新 DNS，也不为未配置监控的实例安装 Agent。代理、SSH 与网络调优材料不属于本次回填范围。

维护者补充已安装桌面的私人归档时，先使用已有主机身份记录只读核对，再在实例锁内更新本地状态、加密材料和校验清单。保护原始实例目录、应用设置、管理密钥和其他实例；原资料与目标文件发生变化时停止。现有旧备份保留原身份与范围，不能直接提升为主控专用自动恢复点。

验证覆盖历史记录待核验、未安装和停用组件、未知布局、完整状态回填、读取失败、凭据漂移、旧证据拒绝、组件元数据保留与只读远端边界。只读真实核对不代表升级、恢复或卸载已经实测。
