# 第三十一轮：证书与运维资源总览

发行更新（2026-11-03）：本轮随 v0.9.41 汇总发行；下文保留实施当时的未发行状态和测试边界，发行验证见 [v0.9.41](TESTING-0.9.41.zh-CN.md)。不代表已安装或应用到生产。

本轮按既定主线实现「证书与运维资源总览，统一到期、使用者、变更影响及维护入口」。源码和隔离验证在 2026-11-03 收尾；当前发行基线仍为 v0.9.40，本轮与第二十八至三十轮均未发行。本文说明功能、操作步骤和验证边界，不代表已安装或已应用到真实实例。

## 1. 入口与管理范围

桌面侧栏新增「运维资源」，实例详情的「证书与运维资源 → 查看资源」进入同一页面并带入该实例。总览读取 Deploy 私人归档，按实例关联、类别、名称／说明和需留意状态筛选；每页 30 项，详情和影响清单竖向滚动。

| 资源 | 展示内容 | 维护入口 |
| --- | --- | --- |
| 固定角色证书 | AnyTLS／ECH、本机自有 HTTPS Reality target 的证书元数据与最近续期计时器状态 | 固定角色证书维护说明、重新只读核对；现有签发与部署钩子仍按原流程维护 |
| 独立入站证书 | 本地导入身份、到期时间、各实际使用者的远端公开证书摘要与域名匹配 | 精确定位「通用多入站」的所选证书 |
| 入站、用户、出站 | 包含停用入站、共享用户及默认／分类去向引用 | 精确定位对应资源类别与身份 |
| 协议与核心 | 固定角色、独立入站各核心的归档版本和使用者 | 选择同一协议的管理／核心升级，或独立入站的对应核心更新 |
| 转发与线路 | TCP／UDP 独立端口映射、WireGuard 槽位与双端通道、跨实例线路 | 对应组件或同一隧道／线路；待恢复的双端和整链事务仍从其专用入口恢复 |
| 客户端来源 | 已保存方案节点及复用组成员与入站、协议、转发、线路的关联 | 打开同一方案；组成员先明确选择引用它的方案，不自动同步所有使用者 |
| 监控与授权 | 已保存的 May Server／Agent、已有受管访问组件、只读授权到期 | 定位同一实例和 May 角色，或对应已有组件维护 |
| 未完成范围 | 草稿或待核对事务的提示 | 实例状态核对；不从总览跳过恢复保护直接改组件 |

Reality 外部 target 使用对端证书，不是当前 VPS 自有证书，不会伪造为本地可续期资源。服务器下一跳的公开信任材料、SSH 密钥、Cloudflare Token、提供商 IPv6 租约等也不冒充本轮受管服务端证书；本轮没有新增这些凭据的签发、轮换或到期推断。

## 2. 如何理解到期与核验状态

有效期按绝对时间判断，展示时转换为桌面本地时间。打开／刷新总览时重新计算；不会持有一个不再变化的「剩余天数」整数，也不新增后台轮询服务。

| 状态 | 含义与处理 |
| --- | --- |
| 有效期正常 | 已知 NotAfter 在 30 天之后；还需单独看证据来源，不能据此认定真实连接正常 |
| 30 天内到期 | 进入维护准备期，先检查使用者与恢复范围 |
| 14 天内到期 | 优先安排证书维护；与已有健康检查的 14 天提醒保持一致 |
| 已到期／尚未生效 | 到期时间已过，或本次远端读取到的 NotBefore 在未来；核对主机时钟与证书 |
| 与归档不符 | 独立证书的远端叶证书摘要与归档不同、同一共享证书的部署副本不同，或使用者域名不匹配 |
| 远端缺失／无法核验 | 固定路径或入站配置不存在、材料无效、路径为链接、工具不可用或读取超时等；保留未知，不补成正常 |
| 归档已变化／快照过期 | 旧核验不再匹配当前归档，或已超过 24 小时；保留明确标注的最后已知信息，重新核对 |
| 最近核验未完成 | 当前读取失败或健康检查被取消／失败；不能回用旧结果显示本次成功 |

本地导入证书保留原有 SHA-256 和 NotAfter；没有使用者的证书仍可查看本地到期信息，不为它虚构远端部署。尚无匹配远端核验的在用证书列入需留意项。未探测的用户、核心版本、方案等只标归档来源，不借用另一项检查的采集时间。

新核验通过当前实例计划和受管配置摘要绑定。随后修改归档，即使只是更名，也会保守地使旧观察失效；总览不会借此自动改写服务器以「修复」差异。24 小时表示页面对快照的新鲜度分类，不表示期间状态永不变化，也不会阻止用户更早重新核对。

## 3. 日常操作

### 3.1 查看与核对

1. 打开「运维资源」，选择全部实例或一台实例及其关联资源。
2. 先看页面是否有「归档读取提示」。无法读取的方案／节点组、缺失来源或损坏记录会使影响清单不完整；不能据此认定资源无人使用。
3. 选「证书」或其他类别，按名称／实例／说明搜索；必要时勾选「只显示需留意的资源」。未筛选部分仍保留，不会因搜索而删除。
4. 「刷新本地归档」重新读本地数据并按当前时间重算，不连接 VPS、不迁移旧方案布局、不保存凭据。
5. 需要当前远端信息时，选择一台已完成纳管且无阻塞事务的实例，点击「核对所选实例（只读健康检查）」。继续使用已有审阅和 SSH 身份确认流程；全部实例视图不能一键跨机器执行。
6. 等待任务结束，分别检查证书状态、核验时间及健康检查提示。任务读完不等于所有资源健康；文件观察也不等于已做协议握手。

核验结果保存在该实例的 `deployment-state.json` 的 `ResourceObservation` 中，原健康记录继续保留。本轮新增字段只保存观察元数据；健康检查仍按原流程更新本地状态和可确认的纳管记录，远端不改证书、端口、服务、Cloudflare 设置或当前代理控制。失败和取消不自动重试原命令，也不会因此签发新证书。

### 3.2 共享证书和其他资源的影响

打开「详情与变更影响」同时看直接使用者与全部受影响项。例如：

```text
共享证书
  → 独立入站（含停用的入站）
  → 复用节点组成员
  → 已保存方案节点
  → 使用该节点的服务器去向／跨实例线路
  → 经线路生成的其他客户端节点
```

用户和出站资源使用相同引用关系。独立入站的 TCP 分类例外也计入出站使用者；两段 WireGuard 各自关联借用它的线路。没有因当前停用、另一地区暂未使用或曾执行过回滚，就解除仍在归档中的引用。

同一图可安全处理循环引用，不无限递归。已结束的 Removed／RolledBack 线路和通道记录作为历史保留，不当作活动安装显示。未知引用显示缺口，不静默替换成其他资源或凭显示名合并身份。

点击「打开维护入口」后再次读取资源身份及归属。资源已移除或维护目标变化时要求刷新；不会执行详情窗口里缓存的旧写入请求。维护表单仍需填写、审阅、确认和实际验收；总览不执行级联轮换、批量删除或自动应用客户端配置。

### 3.3 替换独立入站证书

1. 备份整个私人数据集，核对共享证书的所有直接／间接使用者。
2. 从该证书的维护入口进入「通用多入站 → 证书」，确认选择的资源身份和显示名称。
3. 填入新的证书链与匹配私钥，先核对材料；更换显示名不能代替更换证书身份。
4. 审阅受影响入站、用户及配置范围，执行原有组件事务、受管恢复点和真实协议验收。停用入站保留引用；不应为轮换自动启用它。
5. 重新核对资源观察。旧客户端来源如已失效，应更新来源、预览组／方案差异，重新生成、校验和导出；不直接覆盖正在使用的权威配置。
6. 若应用、验收或提交确认失败，按原独立入站事务核对与恢复，不用另一个入口重放相同变更。

固定角色证书与上述手动导入资源分开。它们继续使用既有 Certbot、DNS 授权和部署钩子；本轮提供到期、使用者、计时器信息及只读核对入口，没有新增自动签发／续期按钮。故障处理见 [Cloudflare／Certbot 手册](CLOUDFLARE-CERTBOT.zh-CN.md)。

## 4. 远端读取边界与信息保护

新增读取器只接受两个固定角色标识和已归档独立入站 ID，由程序映射到固定公开证书路径／入站配置；不接受任意文件路径、命令、URL 或证书私钥路径。一次最多 18 个明确使用者，每个使用者最多两个域名，输入、文件和命令时间均有限制。

独立入站只提取当前配置里的公开证书；固定角色读取受管公开证书文件。OpenSSL 从标准输入解析叶证书、有效期、SHA-256 和使用者域名匹配，不输出 PEM、私钥、用户鉴权、原始配置或原始异常。公开证书块混有私钥、文件不是普通文件、文件或上层路径为链接时拒绝读取。

域名匹配和有效期分别判断；它们不验证完整信任链、吊销状态、部署钩子成功、私钥与远端文件配对或正在运行的服务已加载新证书。实际证书握手及代理业务继续由对应协议验收处理。命令含义参考 [OpenSSL x509](https://docs.openssl.org/3.0/man1/openssl-x509/)，域名匹配与信任验证的区别见 [X509_check_host](https://docs.openssl.org/3.0/man3/X509_check_host/)。

客户端方案和节点组仍为原加密归档。影响分析临时读取后只投影身份、名称和引用关系，清理原对象，不将连接密码、Token、私钥或信任 PEM 复制进资源图。总览本身不读取实例秘密文件；只有用户进入原有维护流程时才按原规则处理对应凭据。

## 5. 失败与恢复

| 情况 | 本轮行为 | 下一步 |
| --- | --- | --- |
| 远端返回缺项、重复身份、未知字段或不符时间 | 拒绝将其保存为有效证书证据，显示本次核验未完成 | 核对只读任务和 SSH／主机时钟后重新审阅检查 |
| SSH 断开或取消 | 不重试读取、不签发、不重启；旧观察不当作本次成功 | 重新打开总览看原采集时间及失败提示，必要时再显式检查 |
| 部分客户端归档损坏 | 其他可读资源仍显示，提示影响范围可能不完整 | 修复或恢复原保护格式；不能因总览没读到就删服务 |
| 草稿／待恢复实例 | 保留资源观察和到期提示，普通组件维护转到实例状态核对 | 按原事务恢复；已识别的隧道／线路待恢复记录进入相应专用入口 |
| 查看后资源又变化 | 打开维护前重新定位，旧身份拒绝使用 | 刷新并重新看影响清单 |

取消资源详情或维护表单不建立远端事务、不生成任务、不改归档。真正开始维护后遵循原流程的取消和补偿范围，不能将「总览只读」套用到之后已明确确认的维护写入。

## 7. 后续范围
