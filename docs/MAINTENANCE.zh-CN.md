# 升级、备份、恢复与排错

适用基线：May VPS Deploy v0.9.38。操作前先完成[使用手册](USER-GUIDE.zh-CN.md)的身份和归属核对。本文描述当前桌面；旧轮次的截图、菜单和路径以[历史索引](HISTORY.md)为准。

## 先分清更新对象

| 对象 | 操作位置与影响 |
| --- | --- |
| Windows 应用 | 设置中的更新流程；校验应用包，保留原安装位置和私人材料。 |
| 远端协议核心 | 实例中选择具体组件和固定目标版本；只改变审阅列出的服务。 |
| 通用入站共享核心 | 显示全部引用者；同版本不当作更新，不用升级偷换凭据／地址。 |
| 证书与用户 | 单独替换／轮换任务；重新验收受影响用户、来源和客户端配置。 |
| May Monitor | 独立 Server／Agent／静态主题生命周期，与代理核心、Tunnel 分开。 |
| 客户端权威文件 | 配置设计中的校验与导出；不因应用升级自动改写。 |

先记录当前版本、文件清单、配置和恢复点，再审阅目标版本、来源 URL、字节数、SHA-256 和支持平台。不要用上游 latest、开发包或其他架构包替换已固定的来源。

## 本地数据保护

备份整个私人数据集，至少包括实例计划、状态、加密秘密、管理密钥副本、主机信任、方案、导出恢复记录和组件备份。备份在原 Windows 用户可读不证明跨系统解密可用；迁移机器前应单独验证恢复。

清空任务列表只删除显示记录，不删除实例、服务器或未完成事务。「删除实例」会审阅本地受管材料；它不是远端卸载。运行中、来源变化或存在待核对事务时应先解决状态，不能直接删 JSON。

## 日常核对

1. 核对实例身份、SSH 主机密钥及当前可用管理入口。
2. 执行只读健康检查，检查服务、启停、版本、监听、配置摘要和证书有效期。
3. 查看是否存在待处理／确认不明事务；优先核对，不从另一入口重复写入。
4. 核对客户端来源、所需地址族、实际协议请求和业务访问。
5. 若维护监控，另查报告年龄、历史推进、磁盘、只读授权到期及告警投递状态。

日志、截图或服务列表含凭据时先脱敏；仅提供排错所需阶段和错误代码。

## 确认丢失与取消

SSH 中断、本机退出或接收不到提交确认，不代表远端没有执行。重新连接后核对同一操作身份、阶段、文件摘要及恢复计时器。已提交、未写入、已恢复和仍待核对要分别处理。

取消先尝试停止后续阶段并恢复当前操作范围，可能不是瞬时完成。若已有恢复保护，不强制抢锁或删除守护单元；若归属不明，不用新事务覆盖旧记录。具体工作台事务见[工作台与恢复](WORKBENCH-AND-RECOVERY.zh-CN.md)。

## 恢复顺序

1. 确认恢复点属于同一机器、组件、事务和合法摘要，审阅会改变哪些文件／服务。
2. 保留当前材料的一致性快照，再恢复所选范围。数据库服务要考虑 WAL 与写入状态，不能只复制一个主文件。
3. 验证原身份、服务状态、配置、SSH 和真实协议路径；监控另验 HTTPS 来源及新报告。
4. 本地归档和远端状态一致后才提交；确认丢失继续只读核对。

「仅恢复配置」和完整组件恢复范围不同。代理恢复不覆盖监控数据；Server 恢复不默认改 Tunnel；Agent 恢复不能代替 Server 数据恢复。旧凭据已撤销时，恢复旧文件也不会让认证重新有效。

## 常见问题的证据顺序

| 问题 | 证据顺序 |
| --- | --- |
| 连接失败 | 本机解析和出口 → 目标地址／端口 → 服务商规则 → SSH／TLS 身份 → 服务监听。 |
| 协议失败 | 对应核心校验 → 真实鉴权／证书 → 请求链路 → 地址族；不要用 TCP 代替 UDP。 |
| 配置源过期 | 对照入站、用户、证书、出站、核心摘要和最近验收；重新选择合法来源。 |
| 更新失败 | 包来源、摘要、当前安装归属、文件占用与更新日志；不要直接覆盖私人目录。 |
| 监控无数据 | 授权范围／有效期 → Server UUID → Agent Token → 报告推进与存储。 |
| 磁盘／资源增长 | 相同阶段的进程 RSS／CPU、DB 与 WAL、清理和 checkpoint 时序；不能只凭瞬时任务管理器截图认定泄漏。 |

网络调优请遵循[网络手册](NETWORK-TUNING.zh-CN.md)和[固定 BBR 内核手册](GOOGLE-BBR-PREBUILT.zh-CN.md)。配置建议、短时测速或内核安装成功均不保证高峰时段改善；应用后仍需在相同条件下复测，并保留可用恢复内核。

## 退役

先决定需要保留的历史、证书与备份，确认新服务已持续上报或业务已迁走，再停用所选组件。共享监听、出站和证书需核对引用者。删除旧备份和外部服务商资料是单独的数据保留决定，不因桌面移除一个实例就自动获得删除授权。
