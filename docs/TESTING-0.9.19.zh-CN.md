# v0.9.19 安装版本选择与网络流程补测

日期：2026-10-12。使用独立的原生后台实例，仅对已授权 VMISS、MOE 专用测试机操作。没有使用鼠标、激活窗口或切换系统代理/TUN；正式应用私人归档没有改动。

## 新部署与追加安装版本

新部署和已有实例追加安装提供“应用固定版本 / 官方最新稳定版”，默认固定版。最新版在执行审阅前通过控制端查询官方发行，沿用设置中的更新代理；锁定各组件具体版本、资产名及 SHA256。共享 sing-box 包只查询一次，仍分别安装到 AnyTLS 与 Shadowsocks 的受管路径。

- 原生新部署表单验证默认固定来源、切换最新版、真实查询及审阅摘要。使用 TEST-NET 夹具，在开始部署前返回；该项属于真实界面与查询验证，不代表另一轮空白系统部署。
- 原生追加安装表单验证默认来源、真实查询、具体版本与 SHA256。VMISS 全部组件已安装时正确禁止覆盖，改用 MOE 尚未安装的主控进行实测。
- MOE 通过正常应用追加官方稳定版 Komari 1.5.1，实际下载摘要、程序身份、主控启动及登录验收通过，安装来源记录为 Latest。独立 SSH 核对原 Xray、Shadowsocks、防火墙和网络文件摘要及运行值不变。
- 本轮主控程序、服务及专属数据目录在测试前确认不存在，验证后按程序摘要和精确服务布局清理。正式主控及原有协议保留。

安装包来源支持官方标签带或不带 `v`。Xray 使用经过独立 SHA256 核验的本地发行包交给固定官方安装器，避免安装器再解析另一个版本。初次执行检查查询有效期；已接受的部署草稿绑定原候选及固定清单摘要，继续时沿用已锁定版本，不重新浮动到另一最新版。未知候选、混入未选择的组件、清单变化及摘要变化停止执行。

## 网络真实流程

| 项目 | 验证结果 |
|---|---|
| AnyTLS / IPv4 完整档 | 真实出口、上下行多轮传输及有限 UDP 样本完成；完成应用、同路径复测及提交/回退流程 |
| 无明确收益自动回退 | 实测比较为 NoClearGain，恢复原运行值、实际队列、持久化文件及原权限；前后记录保留 |
| 采集中主动取消 | 任务为 Cancelled；网络原值不变，本轮隔离测速进程和目录清理 |
| 应用后复测中取消 | 独立读回两项上限从 1 MiB 写到 2 MiB；取消后恢复 1 MiB，并恢复文件内容、权限及队列 |
| 取消定时计划 | 到期后仍为 Cancelled，没有新任务或测量 |
| 协议归档变化 | 为独立私人夹具改变源摘要后，到期检查为 SourceChanged；还原后仍不重跑 |
| 关闭错过计划 | 退出后将夹具到期时间设为已错过，再启动为 Missed，没有新任务或测量 |

网络补测临时降低两项 socket 上限，仅用于验证实际写入与恢复；不据此宣称正常线路需要调优。最终恢复测试前全部网络运行值、持久化文件和队列，独立核对原服务及其他组件文件摘要一致。UDP 只取有限样本，未追逐少量超时。

首次无收益回退发现 sysctl 文件内容虽恢复，权限被私人备份保护从 0644 收紧为 0600。补齐原权限的快照和读回检查，修复后重跑无收益及实际写入后取消，均通过；失败尝试保留，未计为通过。此前受管队列快照继续支持其明确的旧格式。

定时计划首次退出测试未通过，原因是后台会话跳过了启动核对，仅调用到期轮询会执行夹具中的旧计划。后台会话现沿用普通启动的状态核对，但仍不自动启用网络定时器，只接受显式测试命令。修复后退出错过分支通过；夹具到期时间修改不等于真实高峰采样。

## 自动检查与边界

.NET 核心通过 729 项断言，包含安装来源、具体候选、共享包去重、草稿续作、初次安装及组件范围。项目 ValidateProject 通过 888 项主断言及配套交互、配置、更新和 GUI 检查。网络运行恢复 13 项、官方发行解析 6 项通过。真实 Linux 上的初次 Xray 包哈希/URL拒绝 3 项使用隔离命令夹具，不改变系统安装；Debian CI 再验证对应用例。Windows 无符号链接权限的测试由 Unix CI 验证。

新部署按新版本来源在完全空白 VPS 上的整条联网安装尚未新增一轮，原有空白部署与发行维护验证沿用历史记录。部分最新版与固定版同号；本轮没有将这些维护或安装结果当作跨版本升级。真实高峰与非高峰比较、本机直连 IPv6 仍缺条件；不测试断电、完全无法启动等已排除极端故障。
