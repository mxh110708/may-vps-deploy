# May VPS Deploy 桌面使用手册

适用基线：v0.9.39，Windows WinUI 3 桌面。本文中的实例、域名、地址与凭据均为概念或占位符；先从[首页](../README.md)核对支持范围。PowerShell 的数字菜单在[旧命令行参考](CLI-REFERENCE.zh-CN.md)，不能用于推断桌面入口。

## 安装与首次启动

在本仓库 Release 下载同版本 Windows amd64 安装 EXE 或便携 ZIP、文件清单和 `SHA256SUMS.txt`。可使用以下只读命令计算下载文件的摘要，再与发行记录逐字符比较：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '<下载的安装包完整路径>'
```

安装器默认使用 `C:\Programs\May VPS Deploy`，允许选择其他可写目录。已安装版本更新到原目录，不要求为了改名重新建立另一份实例档案。便携版先解压到长期保存的位置，再运行 `May-VPS-Deploy.exe`；不要从压缩包内直接运行。应用自带日常运行依赖，不需要照搬源码构建环境。

第一次打开「设置」，确认私人数据目录、关闭窗口行为和更新设置。不要把私人数据目录指向公共同步盘、源码目录或其他实例的临时文件夹。首次升级前备份该目录，不能只备份 EXE。

## 页面与状态

| 页面 | 任务 |
| --- | --- |
| 概述 | 查看实例和方案数量，进入部署、接入或配置设计。 |
| 实例 | 选择对象，查看状态、做只读核对、组件维护、恢复或退役。 |
| 部署 | 新机、已有实例接入、追加安装；表单结束后审阅，再执行。 |
| 配置设计 | 选择输出目标，编辑节点、连接与分组，生成、校验及导出。 |
| 网络调优 | 采集与建议、显式应用、复测、固定内核维护。 |
| 记录 | 查看任务结果、错误阶段及待处理操作。清理记录不等于清理恢复事务。 |
| 设置 | 外观、字体、窗口行为、更新连接与数据位置。 |

填写表单不连接服务器；任务审阅不是执行成功。运行、失败、取消、待核对和完成各有含义。未知的远端结果不能仅凭桌面窗口已关闭判断为回退完成。

## 选择正确起点

| 当前情况 | 起点 | 关键检查 |
| --- | --- | --- |
| 新购买或重装的专用 Debian VPS | 新机部署 | 有恢复控制台，确认不存在应保留的业务、面板或防火墙。 |
| 已手工部署、布局受支持但未纳管 | 接入已有 VPS | 先只读识别配置和 SSH 身份；未知布局停止，不自动覆盖。 |
| 已受管，增加协议或监控 | 实例维护／追加安装 | 使用原归属和恢复材料，不重新当成新机。 |
| 上次任务中断或确认丢失 | 核对恢复状态 | 核对同一事务、计划、摘要和服务状态，再决定继续或恢复。 |
| 只生成配置 | 配置设计 | 不要求为了生成节点先改远端服务。来源仍需有效。 |

已有 Docker、Tunnel、监控或其他业务不代表不能维护，而是必须选择能明确限定影响范围的操作。服务商网页上的安全组与 VPS 内 nftables 是两层不同配置。

## 新机部署流程

### 1. 准备连接和救援资料

准备服务商／实例显示名、当前连接地址、SSH 端口、root 密码或 OpenSSH 私钥、参考主机指纹、带宽信息和恢复控制台。实例显示名只帮助识别，不能代替 SSH 主机身份。

初次连接会要求核对主机密钥。优先从服务商控制台独立取得参考指纹；明确接受首次信任只证明你接受了该连接，不等于已经通过第三方验证。已信任密钥变化时先确认是否重装，不要直接删除信任记录。

### 2. 选择组件、监听和证书

按用途选 Reality、AnyTLS、SS2022 或其他支持的组件；只出现与当前用途有关的字段。检查地址族、监听、来源白名单、证书、用户及出站。固定角色 Reality 与 AnyTLS 的主 TCP 监听可能冲突，不能把「都已安装」理解成「都能占同一端口运行」。通用多入站模型使用各自独立的监听与身份，也必须避免实际端口冲突。

Reality 外部 target、AnyTLS／Hysteria2 的公共证书、Cloudflare DNS 权限有不同用途。只需已有证书时不要额外申请 DNS 管理权限。证书私钥、用户密码与 SSH 私钥分别保存，不能互相替代。

### 3. 审阅再执行

逐项核对实例、SSH、服务、端口、核心来源、证书、网络参数、防火墙、步骤顺序、本地归档和验收。确认服务商安全组也允许所需端口；应用只能处理自己管理的主机范围。

执行后在主页面观察计划、当前步骤、耗时和结果。取消可能需要等待安全检查或回退结束，不要直接清除事务文件。SSH 或网络断开后先读任务阶段与错误提示，避免反复点击相同写入。

### 4. 验收后生成客户端配置

至少核对新管理 SSH 可用、组件实际启用、监听进程归属正确，并通过对应协议的真实请求。TCP 端口通不等于鉴权成功，TCP 成功也不能证明 UDP 或 QUIC 成功。

保存结果后在配置设计选取已验收的来源，生成隔离候选并校验。最后才写入自己的权威配置；应用内已生成文件不表示 Route／Clash 已加载它。需要删除初始 SSH 或调整服务商安全组时，先确认新的管理与救援入口均可用。

## 接入已有实例

接入会核对当前 SSH，并识别受支持的标准配置。保留来源私钥、现有连接和明确不属于本应用的服务；不把「接入」当作重装。未知路径、归属冲突、缺失凭据或不完整归档会阻止后续维护。

接入结束先做健康检查，对照实际版本、协议、地址族和监听。确认本地实例与服务器一致后再轮换凭据、升级或追加组件。多个控制端不能共用一份正在写入的私人数据目录。

## 通用多入站与 Hysteria2

在实例的「通用多入站 → 管理入站」管理独立入站。监听、用户、证书和出站分别建模；共享资源改变时，审阅会列出全部受影响入站。仅更换显示名不等于更换鉴权身份。

Hysteria2 使用 UDP／QUIC 和 TLS 1.3。准备匹配 SNI 的证书与私钥，分别配置协议密码和可选 Salamander 密码。上下行均为 0 时使用自适应 BBR；设置固定速率须同时填写两个方向，按客户端视角理解。主机与服务商安全组都要允许对应 UDP；同端口 TCP 可连接不能代替 QUIC 验收。

每个用户和导出地址族分别验收。密码、证书、出站或核心身份变化后，旧来源资格会失效，需要重新核对并生成节点。详细参数、更新范围及反例见[Hysteria2 记录](HYSTERIA2-ROUND-14-2026-10-25.zh-CN.md)和[多入站模型](INBOUND-MODEL-ROUND-13-2026-10-25.zh-CN.md)。

第十五轮源码新增「启用端口跳跃」，自 v0.9.39 提供。它要求受管 nftables 和服务商放行完整 UDP 集合，默认间隔 30 秒，使用原服务监听；逐端口验收失败会阻止提交。包含本轮改动的构建按[分享与跳跃说明](HYSTERIA2-ROUND-15-2026-10-28.zh-CN.md)操作，现有发行版不据此推断具备该选项。

## TUIC v5（v0.9.39）

第十六轮源码另提供 TUIC v5 独立入站，自 v0.9.39 提供。在同一管理页面新建协议，使用分别保存的 UUID 和密码，选择匹配 SNI 的证书；默认 cubic、native 数据报、10 秒心跳、3 秒鉴权等待，0-RTT 关闭。保存须同时通过真实 HTTPS 与应用 UDP，不能以 TCP 端口通替代。详细字段、维护及恢复见[TUIC v5 说明](TUIC-ROUND-16-2026-10-28.zh-CN.md)。

## VLESS XHTTP（v0.9.39）

第二十轮源码在通用入站提供 VLESS + TLS／Reality + XHTTP，模式支持 stream-one、stream-up、packet-up 和 auto；TLS 可选 HTTP/1.1／2／3，Reality 限合法的 HTTP/2。填写 SNI、Host、路径和 UUID 用户引用；TLS 选择证书，Reality 使用独立握手目标和密钥。新建默认仍为 HTTP/2、stream-one，可显式更改并审阅高级 extra。服务器出站限直连。

客户端方案可选择配套 May Core 原生配置、可等价表达的 Clash，或双输出；包含 XHTTP 时必须使用具有对应能力和来源记录的 May 校验核心，不能拿上游 sing-box 1.14.2 代替。独立下载参数属于客户端连接，可从完整来源或标准分享链接导入；不能把它当作另一台互不关联服务器的自动会话共享。无法等价分享／转换的字段保留完整原生来源，明确拒绝有损转换。详细流程、证书／密钥轮换、核心更新、启停和局部恢复见[XHTTP 操作说明](XHTTP-ROUND-20-2026-10-29.zh-CN.md)。

## 配置、线路和监控

第十八轮本版源码支持 TLS 的 VLESS／Trojan WS／gRPC 外部节点导入、分享与双客户端配置输出。协议和传输分别展示，路径、Host、serviceName 与 TLS 身份分别保留；复杂路径和无法等价表达的参数会拒绝链接转换。编辑时使用专用表单，更换连接保留节点身份。步骤、限制与实测边界见[外部 WS／gRPC 节点](CLIENT-STREAMS-ROUND-18-2026-10-29.zh-CN.md)。

第十七轮本版源码增加服务器 Hysteria2／TUIC 下一跳。在实例「配置出站」或通用入站的出站引用中选择已保存来源；候选按核心筛选。固定 Xray 原生支持 Hysteria2，本轮不为 TUIC 增加转接进程。默认链路须通过 HTTPS、出口与应用 UDP，附加 TCP 落地继续保持业务规则范围；完整步骤、参数及失败恢复见[服务器 QUIC 下一跳](SERVER-QUIC-ROUND-17-2026-10-28.zh-CN.md)。

客户端草稿、转发目标和多跳链路各自有保存、应用及恢复范围，按[配置与线路手册](CLIENT-AND-LINES.zh-CN.md)操作。不要把本地方案保存成功当作远端转发已启用。

第二十一轮本版源码的「跨实例线路编排」增加 IPv6 TCP，以及 IPv4／IPv6 固定端口 Hysteria2／TUIC UDP。先保存已验收的原始落地来源，从前置实例选择地址族、传输、中转、落地、端口和来源白名单，审阅后执行；三台实例均须同族。UDP 必须通过整链原协议、HTTPS 和应用 UDP 回程，不能以分段选路代替。成功后在配置设计添加转发节点；检查、移除和恢复均从统一线路入口处理，详见[第二十一轮](CHAIN-ROUND-21-2026-10-30.zh-CN.md)。

May Monitor 使用独立 Server／Agent。Deploy 的读取凭据只授予指定节点、限定期限的只读权限，不能复用管理员 Key。首次安装、HTTPS、Agent 凭据核对、续期、静态主题和独立 watchdog 见[监控运维](MONITOR-OPERATIONS.zh-CN.md)。邮件功能需要单独 SMTP 配置和显式启用，安装监控不会自动发信。

## 私人归档与恢复

默认私人数据结构为：

```text
<应用目录>/private/
  instances/<服务商>/<实例>/May-VPS-Deploy/
  client-schemes/
  client-candidates/
  client-publish/
  desktop-settings.json
  ssh-hosts.dotnet.json
  task-history.dotnet.json
```

实例子目录保存计划、状态、加密秘密、SSH 材料及组件备份。方案和部分秘密由当前 Windows 用户的 DPAPI 保护。离线复制目录要包含完整材料，并保留原保护上下文；跨账号／重装系统前要制定实际可用的解密与恢复方案。

实例目录不应散落过期 Deploy 副本。服务商 root 密码／源密钥、Cloudflare 令牌、服务商专用 ATT IPv6 资料属于各自的私人资料管理，不应提交 Git。通用教程不能替代用户对具体文件的保留决定。

## 更新与故障处理

应用更新、远端核心更新、证书替换、监控升级及配置导出是五种不同操作。更新应用不等于更改所有 VPS。按[维护手册](MAINTENANCE.zh-CN.md)先备份、审阅范围和验证结果。

| 症状 | 先检查 | 避免的误判 |
| --- | --- | --- |
| SSH 失败 | 地址、端口、服务商恢复台、指纹和当前认证方式 | 直接删除信任记录或重建全部密钥。 |
| 安装／维护确认不明 | 任务身份、阶段、当前摘要与恢复状态 | 再点一次同样的写入。 |
| 服务运行但客户端失败 | 实际监听、鉴权、SNI、地址族、固定客户端校验 | 以进程存在代替端到端成功。 |
| 双配置只写入一份 | 导出事务、备份摘要、外部文件是否又被修改 | 假定跨文件替换是原子的。 |
| 监控等待或过期 | Token 范围／到期、TLS、Server UUID、上报推进 | 将无数据填成零或宣布线路正常。 |
| 恢复被拒绝 | 是否同实例／组件／事务，摘要和文件归属是否一致 | 拼接旧脚本覆盖现有服务。 |

发生错误时保留应用版本、入口、任务阶段、错误代码和脱敏日志，再选择受管恢复。完整恢复也不应覆盖不在选定范围内的监控、Tunnel、代理或 SSH。删除任务记录不能解决未确认事务。

## WireGuard 双实例加密通道（v0.9.39）

从实例详情选择「管理隧道」，指定另一台可信受管实例、外层 IPv4／IPv6、两端 UDP 端口及私网地址；审阅后执行双端预检、恢复点、内核配置和双向 TCP／UDP 验收。待恢复时从实例页「恢复两端隧道」进入，不能用单机恢复拆开处理。不会自动改变现有三机线路、默认路由或 DNS；完整步骤、对端访问范围与边界见[第二十二轮](WIREGUARD-ROUND-22-2026-10-30.zh-CN.md)。

## 节点组复用（v0.9.39）

在配置设计的节点页保存选中成员与完整入口依赖，再在其他方案中选择复用。组更新后逐个方案查看差异并同步；本地修改冲突时保留原值，必要时解除关联后独立使用。变更会使候选失效，生成、核心校验及实际导出前重新核对版本与来源。完整配置和分享链接使用同一组来源，不能将分组或不可表达参数塞进有损链接。详细操作与故障处理见[节点组手册](CLIENT-GROUPS-ROUND-23-2026-10-30.zh-CN.md)。
