# 审计修复与隔离升级验证（2026-10-01）

## 范围

本轮只更新 MXH-VPS-Deploy 项目及公开验证资产。未连接、升级或修改生产 VPS，未更改个人权威配置、系统代理、TUN 或桌面程序状态。版本清单更新不会使已有实例自动升级。

固定版本：Mihomo **1.19.32**，Linux/Windows sing-box **1.14.2**，Komari Controller **1.5.1**、Agent **1.5.11**；May Route 客户端基线保持 **1.14.2-mxh.7**。资产 SHA-256 记录在版本及 vendor 清单中。

## 修复对应关系

| 审计项 | 修复与边界 |
| --- | --- |
| A01 健康审计执行 Agent、无超时 | 不执行 Agent；用文件哈希识别已知发布。子命令限时 10 秒，超时明确标为检查不完整。 |
| A02 通用 Controller 升级遗漏备份/迁移 | 通用与专用入口复用同一流程，传递 Controller 专属一致性备份，等待人工迁移并复验。 |
| A03 主控恢复覆盖新旧数据库 | 停服务并确认已停止，再备份当前状态；校验归档及上传哈希，隔离现有目录后还原，失败恢复操作前数据。停止命令返回成功但服务仍运行时，拒绝复制或还原数据库。旧版本号从恢复后的实际程序读取。 |
| A04 协议回滚覆盖实时监控 | 按组件限定快照及恢复范围；历史协议快照含监控文件时也过滤，不替换当前监控计划和凭据。 |
| A05 纳管/轮换丢失 IPv6 和自定义配置 | 导入保留 IPv6 源地址/接口；升级保留现有配置，轮换只改变已识别字段，核对原配置 SHA-256。多用户或不明确的布局拒绝自动处理。 |
| A06 保留 SSH 策略被最终检查否定 | 最终检查沿用导入时明确选定的认证策略，但始终要求公钥认证和管理端口有效。 |
| A07 Tunnel Token 未作用于进程 | 显式重启 Cloudflared，核对 MainPID、程序及运行参数中的 Token。不将进程启动视为云端隧道已连通。 |
| A08 健康判定缺乏关键证据 | 检查 TCP/UDP、AnyTLS/本机 Reality 证书、续期计时器、主控/隧道状态及运行程序；缺证据不能判定健康。 |
| A09 旧客户端发布绕过校验 | 两个入口使用共同的 Ready、来源/候选/目标指纹、成对备份和恢复记录；跳过只能保留候选。 |
| A10 状态与归档记录不一致 | 核对并同步实际监控状态；卸载移除版本记录；导入复用归档校验函数，不把追加日志算作固定归档。升级验收的跳过项记录为不完整并告警，不显示全部通过。 |
| A11 核心缓存只信任 ZIP 标记 | 核对缓存 EXE 的哈希、精确布局和实际版本；显式重试重建缓存，不选择任意同名 EXE。 |
| A12 扫描误读本地私有运行数据 | Git 模式只扫描公开、非忽略文件，但暂存/跟踪的私有路径仍失败；源码包模式使用明确的运行数据边界。 |

另外，写入命令执行前校验事务所有者和截止时间，长时间下载结束后复验；过期或已回滚的事务拒绝后续写入命令和提交。已开始的写入阶段与回滚用同一锁协调；回滚服务拿不到锁时会重试，而非永久放弃。不能承诺精确在保护窗口截止秒完成还原。

## 二次审计修复

| 复审项 | 修复与回归 |

| R01 主控专属备份误删隧道 | 本地预览和远端均从归档成员识别恢复范围；主控专属备份的外层事务、成功恢复和失败回滚均不操作当前 Cloudflared。隧道归档须包含服务和程序；完整恢复后隧道启动失败会恢复当前文件及数据库。覆盖实际项目备份后恢复、部分归档拒绝、停用状态和 UI 事务范围。 |

## 核心与 GeoData 资产

当前包只保留清单引用的 Windows ZIP。移除的 sing-box 1.14.0、Mihomo 1.19.30 Windows 包另存于本地 `.tmp/retired-client-cores-20261001/`，也可从旧 Git 版本恢复。Linux 回归所需的旧核心仅下载到忽略的临时目录。

GeoData 使用 2026-10-01 的固定文件哈希和 GitHub 资产 ID。重建覆盖核心 ZIP、GeoSite、GeoIP 和五项 SRS；完整文件均通过校验时，无需联网。离线来源须是本版本的已校验 vendor 目录，例如从完整发布包取得：

```powershell
./scripts/Sync-ClientValidationAssets.ps1 -SourceDirectory <本版本的-vendor/test-cores/windows-amd64> -Offline
```

损坏文件默认拒绝覆盖。明确增加 `-RepairExisting` 后才隔离旧文件并替换。上游若删除历史资产 ID，请从本版本的完整发布包恢复，不将 `latest` 的新数据配上旧哈希。

`Check-UpstreamVersions.ps1` 现在分别报告 Linux/Windows sing-box、Mihomo、May Route、Xray、Komari；一项查询失败不妨碍其他结果，不执行自动升级。
