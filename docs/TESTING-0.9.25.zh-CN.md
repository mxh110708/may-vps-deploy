# v0.9.25 实例发现边界修复

日期：2026-10-14。

问题来自将整个 instances 树中的 deployment-plan.json 都当成实例。更换 IP 时保留在某个实例内部的旧计划因此出现同名条目；它不满足三层实例路径规则，删除审阅会正确拒绝该路径。

修复仅在服务商/实例/MXH-VPS-Deploy 固定层级读取计划，并核对计划的 Provider、Instance 与真实目录名称一致。嵌套备份不参与发现。没有通过放宽删除规则来处理错误条目，也没有只按显示名去重。

验证范围：

- .NET 回归覆盖更换 IP 备份、较深备份、非标准目录、身份不匹配、合法草稿及同 NodeName 的不同真实实例。
- 所有列出的实例路径均能通过操作路径校验；嵌套备份仍不能单独进入实例删除流程。正常实例可审阅删除范围，审阅后变化、运行锁、未确认事务与链接保护继续验证。
- 原生 WinUI 后台夹具复制一个更换 IP 备份，核对选择框只列出一次正常实例、能够打开正常删除审阅并取消，备份文件保持原样；测试不激活前台或连接生产 VPS。

现场只读确认安装版为 v0.9.24，重复条目对应正常归档内部的 IP 更换备份。此次没有删除、移动或改写用户归档，也没有变更服务器或权威配置；更新应用后按新发现规则刷新列表。

本地完整 .NET 回归通过 888 项断言。使用修复后的 Core 只读读取实际安装版归档，结果为 5 个规范实例、1 个 AetherCloud，备份计划摘要保持一致；辅助程序拒绝读写凭据。
