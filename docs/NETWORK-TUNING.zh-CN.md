# 网络调优（WinUI v0.9.15）

部署完成或接入实例后，在“网络调优”选择 VPS。网络配置独立执行，部署、协议追加和切换不会隐式调优。

## 落地机

落地机只启用默认接口 fq 与当前内核可用的 BBR。无需填写带宽和 RTT，也不运行精细测速、不调整缓冲区、TFO 或 MTU。已有受管文件中其他参数的持久化内容保留。

实际队列以 `tc` 为准。`mq` 根队列可以保留，其发送叶队列使用 fq。已有 fq 的参数保持原样；遇到 cake、htb、netem 或不能完整恢复的布局时，应用在写入前停止，交由维护者核对。

## 入口机

1. 填写服务商的标称下载/上传带宽、共享/独享/突发类型；未知可留空或选“未知”。标称带宽与测速分开保存，不读取虚拟网卡速率来代替套餐信息。
2. 选择启用的 Reality 或 AnyTLS 入口和连接地址族，以及主要使用地时区、晚高峰窗口。RTT 由应用采集，无需用户填写。
3. 点击“采集并生成建议”，审阅测试对象和流量预算后开始。主页面分条显示执行阶段。
4. 查看真实 TCP RTT、单连接/4 连接的上下行吞吐、空闲及传输中响应时间、抖动、CPU/steal、内存、TCP 重传段差值和有限 UDP 样本。
5. 有足够有效数据时审阅建议；应用参数后按相同路径和档位复测。没有明确收益、出现延迟代价或结果不足以比较时，恢复原运行值和实际队列，保留前后结果。测速完整完成并不保证调优一定有收益。

测速使用隔离的 sing-box 回环代理。本机系统代理、TUN、鼠标和前台窗口不变。入口路径是“本机→所选协议入口→Cloudflare 测试点”；另列“VPS→Cloudflare IPv4”补充测速。结果不代表所有网站、整天容量或服务商承诺带宽。核心与配置校验均使用项目固定版本。

轻量档有效载荷最多 32 MiB，完整档最多 256 MiB；预算包括额外 VPS 出口测速。HTTP/TLS 开销和 SSH 采集不属于有效载荷。路径测量分别限制为 100/240 秒，另外还有有限的 SSH 状态读取；超时不反复重试。UDP 只发送 5 次 DNS 小样本，未响应如实记录，不据此断言线路丢包率。测试端点沿用 [Cloudflare 官方测速实现](https://github.com/cloudflare/speedtest) 的下载和上传接口，不使用已废弃的公共 TURN 丢包服务。

真实 TCP RTT 来自 VPS 选定入口、与当前 SSH 来源对应的连接。SSH 和代理如果来自不同出口而无法对应，应用不借用其他用户连接或 HTTP 响应时间来估算缓冲。TCP 重传和网卡丢弃是全机/接口计数，不能当作所选线路的丢包率。原始只读证据保存在私人归档的 `network-measurements` 中。

建议采用有上限的 socket 缓冲天花板，保留内核自动缓冲及现有较高值，不预分配内存。按实际内存限定新增天花板；CPU 或 steal 较高、出口不一致、RTT/传输缺失、现有缓冲上限未确认或已超出保守预算、标称带宽未知、测速未完整完成时，只提供基础配置，并说明原因。此版本不自动设置全局限速，也不承诺消除共享线路拥塞。

## 测试时间

早间数据不会转换为预测的晚间数据。没有同路径、同协议、同地址族、同使用地时间窗口的近 7 天晚高峰证据时，建议明确标记“未覆盖晚高峰”。有历史证据时，将保守容量用于建议，原始实测速率仍单独保留。

“审阅晚高峰补测”安排下一次窗口开始时的一次性测量；可以关闭到托盘，但应用必须运行。它不自动应用建议、不新装 Windows 服务、不打开凭据或身份确认弹窗。应用关闭而错过时间会记录“未执行”，中断的计划不自动重试；需要用户重新安排。归档协议变化时停止旧计划。其他任务占用超过开始后的 30 分钟窗口也会记为错过，避免后来突然开始测速。

## BBR 版本与恢复

`bbr` 名称本身不表示 v3。应用读取运行内核已加载模块的版本证据，无法确认时显示“版本未确认”。已支持 v3 的内核可以按同一流程启用和核验；当前正式发行不自动下载内核或重启 VPS。Google 的 [BBR v3 实现与说明](https://github.com/google/bbr/tree/v3) 需要匹配的内核构建，内核升级应作为独立维护任务审阅。

写入前保存受管 sysctl 文件、实际运行参数、接口队列及受管持久化服务，启用限时回滚。写入时使用事务身份与锁；结果不明确时先核对状态，不重复执行。恢复既还原文件，也还原内核运行值；发现外部更改或链接则停止覆盖并保留材料。网络恢复不包含协议、SSH、防火墙和监控数据。

精细建议绑定测量文件摘要与实例协议身份；超过 24 小时、记录变化、运行内核/参数/队列漂移后需重新测量和审阅。传统 PowerShell CLI 的历史调优模式仍按其原有计划运行；本页自动采集流程属于新的 WinUI/.NET 实现。
