# 第43轮：远程模板与规则来源

纳入 v0.9.43。该功能复用第38轮模板修订和第26轮规则快照，不安装后台任务，也不执行远程脚本。

## 入口与流程

在“配置设计 → 客户端模板库 → 远程模板与规则来源”登记来源。选择客户端模板 JSON 或域名／CIDR 规则集 JSON，填写 HTTPS URL、下载网络和可选的固定 SHA-256。访问令牌可以放在 URL 查询参数中，来源、缓存和完整文本均进入私人加密归档；列表与审阅只显示名称、主机名和摘要。

1. “获取最新修订”先获取并校验数据，写入不可变缓存。
2. “缓存、差异与历史”选择修订，核对摘要、变化字段及已有使用者。
3. 确认只将该版本加入模板／规则库，不改变使用它的方案、实例或导出文件。
4. 模板从原有应用差异入口应用到已保存方案；规则从服务器分类编辑器选择固定版本，按原有服务器事务审阅和验收。
5. 恢复模板应用使用第38轮的范围恢复；选旧缓存可派生新的模板修订。规则库可选择历史快照；已部署使用者仍须单独审阅更新，不能把切换库版本当作已恢复服务器。

## 格式与固定身份

模板采用 `ClientTemplates` 的完整 JSON：Schema、Id、Revision、Name、ParentFingerprint、Clients、Parameters、Layout、Bases、Cores。基础内容只接受无固定代理节点／代理订阅的 Mihomo YAML 或 May Route JSON，沿用现有解析器、参数、组引用和依赖检查。远程声明的核心身份不能替换本机校验核心；导入时绑定应用随附的固定核心。

规则沿用 `ServerRuleSets` 的版本化格式：Schema、Id、Name、Revision、Rules；Rules 仅含 Domain、Suffix、Cidr 匹配项。动作和去向由使用者配置。原生 SRS、DAT、任意脚本或递归规则不能直接作为该 JSON 来源。模板内部的 HTTPS 规则／GeoData 依赖继续按声明记录，不因登记模板而自动下载为受管规则修订。

同一来源的远程对象身份固定；同一修订返回不同字节会拒绝。内容完全相同的重复获取不产生新缓存。模板导入使用来源独有的本地模板身份和连续修订，不接管同名内置或私人模板。单个缓存最多512 KiB，每来源最多32个修订，共32个来源；达到上限不自动清理历史。不同来源地址登记为新来源，不原地替换已有来源身份。

## 失败、取消与恢复

下载复用现有受限下载器：30秒总时限、8秒连接时限、最多3次重定向、512 KiB解压后上限和严格UTF-8。每次重定向重新检查地址，不允许 HTTPS 降级，不带跨请求 Cookie。获取失败、摘要错误、格式错误、同版本内容冲突和取消均保留原缓存及使用者。

缓存写入前重新核对来源身份。导入审阅固定来源缓存、库当前版本、候选内容及使用者清单；任一变化需重新预览。保存库修订使用原有原子存储和锁。重复导入同一内容不新增模板版本；确认返回不明时核对库身份，不重放修改使用者。模板实际应用仍有准备／完成／恢复事务，保留节点、凭据和导出位置。

## 验证

`--remote-library-only` 和 `--group clients` 覆盖20项来源及模板闭环断言：获取不自动应用、失败与取消保留、摘要固定、身份和同修订冲突、审阅篡改、过期预览、使用者影响、连续版本、旧缓存恢复、规则历史选择及脚本拒绝。底层下载器的网络、超时、重定向和大小限制复用已有行为回归。

以上是合成来源及本地配置核心验收，不代表第三方公网来源持续可达。通用操作与恢复见[第38轮](CLIENT-TEMPLATES-ROUND-38-2026-11-14.zh-CN.md)及[第26轮](SERVER-RULESETS-ROUND-26-2026-11-01.zh-CN.md)。
