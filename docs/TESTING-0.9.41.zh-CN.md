正式包从干净 `main`、稳定应用元数据 v0.9.41 构建，不使用 Development 或 QA 安装包。安装器代码和应用安装身份没有改变，因此不重复实际安装／卸载；打包仍执行原生 `--verify-runtime` 的隐藏启动核验。

原始测试记录中的模拟系统、合成服务、loopback 和虚拟机分别保留其证据范围。此次汇总回归不增加 Debian 整机生命周期或真实生产切换证据；先前有明确限制的 Vision、XHTTP、WireGuard、应用 UDP 和 PROXY 场景仍按各轮支持矩阵使用。
