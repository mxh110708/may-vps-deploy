# 第十七轮：服务器 Hysteria2／TUIC 下一跳

本轮扩展的是**入口服务器向下一跳发起的代理连接**。客户端选择地区、透明端口转发、跨实例编排和服务器固定下一跳分别管理，不能相互替代。当前发行基线仍为 v0.9.38，第十五至十七轮属于尚未发行源码；本文不代表已安装应用或生产 VPS 已更新。

## 支持范围

| 入口及运行核心 | 本轮新增下一跳 | 保留范围 |
| --- | --- | --- |
| 固定 AnyTLS 入站，sing-box | Hysteria2、TUIC v5 | 原 Shadowsocks／SS2022、默认落地、TCP 分流例外、附加落地和归属检查。 |
| 独立 AnyTLS、SS2022、Hysteria2、TUIC 入站，sing-box | Hysteria2、TUIC v5 | 共用出站引用、逐用户与地址族验收、局部恢复。原有直接出站及受支持 VLESS／AnyTLS 参数范围保持原逻辑。 |
| 固定 Reality 或独立 Reality 入站，Xray | Hysteria2 | 固定 Xray 26.3.27 的原生实现；原 Shadowsocks 下一跳保留。 |

固定 Xray 没有 TUIC 实现，所以界面过滤此组合，模型也明确拒绝。没有为它增加额外的 sing-box 转接服务。未添加 VMess、旧版 Hysteria、TUIC v4 Token 或其他旧协议，也没有将本轮扩大为任意服务器协议转换器。

主机必须具备到所选下一跳的 UDP 网络条件。入口可以向用户提供 TCP 协议，而入口到下一跳仍使用 QUIC／UDP；因此入口 TCP 可达不能证明整条链路可用。TLS 1.3、SNI 和证书验证保持启用，TUIC 0-RTT 保持关闭。

## 选择和应用

### 已有固定角色

1. 在配置设计导入并保存具有完整 sing-box 原生参数的下一跳，核对所选 IP、协议、用户、TLS／SNI 与预期网站出口。导入本地方案不会修改服务器。
2. 进入实例的「配置出站」，选择目标入站组件和默认下一跳。候选按实际运行核心筛选；切换组件保存各自的未提交草稿。
3. 填写预期网站出口 IP。该值用于实际验收，不是监听地址，也不应照填入口机地址。
4. 如需分流，继续使用已有目标域名／网段规则及附加 TCP 落地。附加落地的“TCP”指承载的业务规则；它连接 Hysteria2／TUIC 时仍使用 QUIC 传输。UDP 业务保留原规则语义，使用默认落地。
5. 审阅影响范围并执行。只重启所选组件；默认链路验证实际 HTTPS、出口地址和应用 UDP，附加 TCP 落地从入口机独立检查协议、TLS 及出口。
6. 失败或取消恢复该组件本次变更；失去提交响应先核对事务，不重复应用。移除固定链路恢复原有出口策略，并保留入站身份及其他组件。

### 通用独立入站

1. 在「通用多入站资源 → 出站」新增出站，选择「已保存代理节点」，然后选择 Hysteria2 或 TUIC 来源。
2. 明确出口地址族和预期出口。由相应入站引用该出站；共享引用变化时，审阅会列出所有受影响入站。
3. Reality 使用 Xray，不能引用 TUIC。它可以引用完整可转换的 Hysteria2；不支持的拨号／TLS 参数在生成配置前拒绝，不会静默删去。
4. 保存后，每个受影响用户及地址族都须通过实际 HTTPS 和有限应用 UDP 验收。HTTPS 成功而 UDP 失败时不能提交，也不能导出为已验收来源。
5. 更新客户端节点时，仍从已验收的**入口**生成客户端配置。服务器的下一跳凭据属于入口服务器配置，不会额外塞进用户的入口节点。

## 参数对应与限制

| 参数 | sing-box 服务器出站 | Xray Hysteria2 对应 |
| --- | --- | --- |
| 地址／端口 | 显式 IP 和 `server_port` | `settings.address`／`port`，`version=2`。 |
| Hysteria2 密码 | 原样保留 | `streamSettings.hysteriaSettings.auth`。 |
| TLS／SNI | `tls.enabled`、`server_name`，不跳过验证 | Hysteria 传输、TLS 1.3、`tlsSettings.serverName`、h3 ALPN。 |
| 公开信任证书 | 可显式保存有限 PEM；不接受远端文件路径 | 转为 `usage=verify` 的公开信任证书，限定其信任范围。 |
| Hysteria2 两向带宽 | 保留两个整数 Mbps；两向同时为零或不设置时自适应 | 自适应 BBR；正数对应 `finalmask.quicParams.brutalUp`／`brutalDown`。 |
| Salamander | 保留独立混淆密码 | `finalmask.udp` 的 Salamander 配置。 |
| Hysteria2 跳跃 | 最多 256 端口，保留间隔及可选最大间隔 | `finalmask.quicParams.udpHop`；端口和间隔完整转换。 |
| TUIC 身份 | UUID 与密码分开保留 | 不支持，明确拒绝。 |
| TUIC 其他参数 | cubic／new_reno／bbr，native／quic，有限心跳，0-RTT 关闭 | 不支持，明确拒绝。 |

当入口服务器连接下一跳时，入口服务器是该段的客户端。因此 Hysteria2 的上行表示入口→落地，下行表示落地→入口；不能把它与终端用户到入口的带宽混为一谈。QUIC BBR／Brutal 也不等于 Linux TCP 拥塞控制设置。

本轮下一跳仍使用显式、非回环且非链路本地的 IP 端点；域名端点需要另行补充远端解析与环路约束。拒绝客户端 `detour`、插件、接口／源地址绑定、额外封装、未支持的 TLS 参数及远端证书文件路径。出现这些参数时先保留原方案，再选择符合范围的节点；不能删除参数后宣称等价支持。

固定 sing-box 的 `server_ports` 对单独端口同样要求范围语法。本轮修正单端口和不连续集合的原生输出为 `端口:端口`，连续范围保持原意义。导入、分享和双客户端检查继续验证端口集合对应，不改变服务商放行要求。

## 来源与恢复

来源引用包含方案、节点及参数摘要。应用前重新核对来源，归档变化或审阅后变更会中止；不会随来源刷新自动修改服务器。独立入站来源还核对其实际应用、用户／证书／出站摘要、运行状态及验收记录。凭据轮换、停用、来源失效或循环依赖不能被旧节点副本掩盖。

服务器上的配置采用明确快照。来源后来变化时，状态页提示重新选择和审阅；已经运行的快照不会被后台自动替换。移除／恢复服务器链路可以按本地归属处理已知配置，不要求先把已删除来源找回来。

固定角色变更使用该组件的专用恢复点；独立入站变更使用受影响入站及本次自有防火墙范围。无关入站、其他防火墙表、SSH、监控和 Tunnel 不属于本次改写范围。恢复配置不等于修复物理网络，仍需在网络恢复后重新检查路径。

## 验收范围与证据

控制端的 UDP 探测复用已启动的隔离客户端 SOCKS UDP 通道，控制端只发送到自己的回环中继。匹配中继、目标、DNS ID、原问题和回答，不能用直接 DNS 或只成功的 HTTPS 冒充。该检查是有限 DNS 业务样本，不保证所有 UDP 应用、大包或公网吞吐。

附加 TCP 落地在入口机使用同一固定核心建立有限的隔离代理，完成协议鉴权后发出 HTTPS 请求并核对出口；QUIC 结果额外记录实际协议和传输。探测进程、配置和公开信任材料随任务关闭，不新增常驻轮询。

本轮隔离验证覆盖双客户端连接入口后，经服务器 Hysteria2／TUIC 下一跳到受控 HTTPS 与 UDP DNS；固定 Xray Hysteria2 的基本、带宽／Salamander／跳跃参数也使用实际核心验证。断开 QUIC 传输不得回退直连；错误 DNS 不能成为 UDP 证据。模型验证还覆盖来源变化、旧受管身份、UDP 证据缺失、审阅与恢复范围。

Debian 12／13 各通过 15 项真实生命周期断言，包含 AnyTLS→Hysteria2、SS2022→TUIC 的 HTTPS／UDP、错误 SNI、UDP 阻断、精确配置与防火墙恢复、无关服务身份、启停、提交响应丢失、来宾重启和移除。临时源服务随验收停用，虚拟机已关闭。测试使用 DMI／文件身份标记；Windows→WSL 测试桥只封装该段测试数据，来宾收发真实 UDP。

原生 WinUI 检查覆盖核心能力筛选、切换草稿、审阅不显示 UUID／密码及取消隔离；前台激活与前台采样均为零，测试实例已关闭。项目主回归通过 956 项主断言及交互、工作台、审计、更新、Python／Bash 检查；新的远端参数边界包含五项 Python 测试。

最终完整 .NET 回归通过 2534 项断言，包含固定 Xray、Mihomo、sing-box 以及第十五至十七轮的真实协议测试；本轮模型／真实链路新增 98 项。独立固定双客户端兼容和各 16 项实际分流检查通过，620 个公开文本文件秘密扫描通过。Windows 缺少符号链接权限的两项通用断言按既有规则跳过，Unix CI 负责其对应分支。编译成功，但 NuGet 漏洞源不可达产生 NU1900 警告，不能据此宣称完成新的依赖漏洞扫描。

初次来宾测试暴露了夹具只转发 TCP 的缺口；补齐 SS 同端点的受限 TCP／UDP 桥后，又修正了重跑时合成 HTTPS 进程仍持有上一轮证书的问题。早期失败均保留为失败，未放宽产品验收条件。公网线路、完整 IPv6 联网和长期资源稳定性不属于本轮已验收范围。
