# 监控支线 M3：独立 HTTPS 接入与单节点试迁移验收

编号纠正：本文件记录监控支线，历史文件名中的轮次不代表原主线完成。跨实例编排、通用多入站和 Hysteria2 的状态见[主线路线图](DEPLOY-ROADMAP-2026-10-24.zh-CN.md)。

日期：2026-10-24。延续 Komari 与 May Monitor 并存、逐节点迁移。本轮完成源码和隔离验证，没有安装用户应用、发布更新、修改生产路由或停用旧监控。

## 已实现的流程

「监测」页新增「接入与验收」，分为两步：保存本机接入计划和指引，再显式审阅只读检查。计划保存不连接服务器、不调用 Cloudflare API、不创建 DNS 或连接器。

| 功能 | 本轮行为 |
| --- | --- |
| 独立接入计划 | 选择 May 服务端实例、独立 HTTPS 根网址；记录本机端口和服务安装身份。 |
| 原路由保护 | 拒绝已归档 Komari 使用的同一公开主机名，避免试迁移覆盖旧入口。 |
| 接入指引 | 给出同机连接器的回环服务 URL、路径／WebSocket／鉴权和缓存注意事项。指引可折叠，切换检查范围仍保留。 |
| HTTPS 核验 | 经 SSH 核对所选 May 服务，再经正常 TLS 和专用只读凭据核对响应中的安装身份。版本相同不能替代身份相同。 |
| 单节点验收 | 核对实际 Agent 凭据、归档端点、节点 UUID 和服务端身份；连续读取有效上报。 |
| 结果失效保护 | 计划、令牌／绑定、服务或 Agent 归档变化后，旧通过记录不再显示为当前可用。 |
| 取消／失败 | 清除本次通过状态；不生成远端变更事务、不启停服务、不重放操作。 |

## 配套版本与身份

配套源码候选为 Server `0.1.0-rc.3`、Agent／Web `0.1.0-rc.1`，Deploy 仍为尚未发行的 `0.9.36` 候选。本轮没有取用新的上游分支或改变远程控制、扩展、自动更新等默认关闭策略。

安装／升级 May 服务端时，生命周期程序为该安装生成一次随机 UUID，保存到受管记录和 root 私有环境文件 `MAY_MONITOR_INSTANCE_ID`。它不来自硬件 UUID、机器 ID、提供商账号、IP 或凭据。

独立只读快照新增可选 `server_instance_id`，已认证 Agent 凭据核验也返回该身份。身份不是新的授权令牌，不产生管理权限；匿名及独立只读凭据仍不能变成 Agent／管理员。原快照 schema 保持 1，旧只读客户端可忽略新字段；没有身份的服务仍能提供原指标，但不能通过本轮来源核验。

常规升级、同组件恢复和重启保留已有身份。恢复到引入身份之前的旧快照后，必须重新升级、核对并保存接入计划；不能把旧版缺失身份当作核验通过。

## 首次接入顺序

1. 按监控支线 M2流程部署或升级 May 服务端，并只读核对安装状态。
2. 打开「接入与验收」，选择该实例，填写新的 HTTPS 主机名，点击「保存计划与生成指引」。
3. 按指引在你控制的发布渠道配置独立路由。保持旧 Komari 路由及数据。
4. 打开新的 May 管理界面，创建试用节点，取得该节点独立 Agent Token 和 UUID。
5. 在 Deploy 配置专用只读连接，填写同一 HTTPS 根网址、只读令牌和明确的实例／UUID 绑定。
6. 通过监控支线 M2「应用本机只读授权」下发摘要、节点范围和期限。原始只读令牌留在控制端。
7. 为一个实例安装 May Agent；也可以核验先前已经部署的 May Agent，不必为增加身份支持重装或改写 Agent。
8. 先运行「核验 HTTPS 与服务身份」，再选择一个 Agent 执行「单节点试迁移验收」。
9. 通过后保留旧监控继续试用。何时停旧服务、迁移历史或扩大节点范围，另行明确选择。

保存接入计划后更换网址，需要重新保存；仅切换检查范围不会丢失尚未保存的网址。关闭表单不启动远端任务；此前明确点击保存的本机计划继续保留。

## HTTPS 发布路径

当前入口要求独立 DNS 主机名、HTTPS、443 端口和根路径，不接受账号信息、查询参数、片段、回环或与旧 Komari 相同的主机名。它不负责自动创建证书、Tunnel、云端路由或 Access 策略。

若 `cloudflared` 与 May 服务端在同一 VPS，可将新的 published application route 指向 `http://127.0.0.1:<May监听端口>`。同机回环的 HTTP 是连接器到应用的本机连接，控制端和远端 Agent 的公开接入仍使用 HTTPS。不要把回环监听端口直接开放到公网。

Cloudflare 路由把公开主机名映射到服务 URL，一个 Tunnel 可以发布多个应用；选择新增独立路由时保留原路由。配置位置及参数应以 [Cloudflare 官方接入文档](https://developers.cloudflare.com/tunnel/get-started/)和[路由说明](https://developers.cloudflare.com/tunnel/concepts/routing/)为准。本入口不要求用户为生成指引交出 Cloudflare Token。

也可使用自行管理的 HTTPS 反向代理。代理应保留 API 路径、`Authorization` 和 WebSocket 升级，不缓存 API 快照。若 Access 返回登录页或重定向，控制端会停止，不会代为绕过访问策略或向重定向地址发送令牌。公开路径和真实 Cloudflare 网络仍由用户选定后单独验收。

## 实际核验边界

HTTPS 核验依次检查：

1. 本机保存的计划和加密只读来源没有变化。
2. 所选 VPS 的 May 文件、账号、服务进程和摘要符合归属记录，服务正在运行。
3. 回环监听端口、受管安装身份与计划相同。
4. 公开 HTTPS 使用正常证书校验，返回独立只读快照。
5. 快照安装身份与经 SSH 取得的身份完全相同，返回节点没有超出本机绑定范围。

安装身份用于比对受管应用实例，不是硬件证明；手动复制整套身份及数据属于运维者明确改变部署边界的行为，不在身份不可复制的承诺之内。

单节点验收还会经该节点原管理连接执行只读 `VerifyAgent`：核对实际配置摘要，并用配置中的 Agent Token 调用中性凭据核验接口，只返回节点 UUID、May 身份、端点和状态摘要。Token 不回传控制端，不生成伪造指标或注册节点。

Agent 的实际端点必须与它的归档相同。它可以使用该服务的其他 HTTPS 地址；同机 Agent 也可使用回环地址，只要经凭据核验确认是同一个 May 实例。不会因为 Agent 的内部连接地址与公开网址不同而要求重装。

## 连续上报与状态

正常情况下读取三次快照，间隔 3 秒，窗口约 6 秒；网络与 SSH 时间另计，整项检查最多 60 秒。每次都重新检查来源和安装身份，要求节点在线、指标有效、时间新鲜且不倒退，并且至少两次上报时间不同。

试迁移快照与节点采样采用 15 秒新鲜度边界；原监测页的 90 秒显示策略保持不变。这里的 CPU 和内存值是节点主机指标，不是 Agent 进程本身开销；该短窗口也不证明网络吞吐、长期稳定性或告警投递已经验收。

| 状态 | 含义 |
| --- | --- |
| `HttpsVerified` | 本次 HTTPS 与安装身份核验通过，尚未代表 Agent 已可迁移。 |
| `ReadyForTrial` | 指定单节点的凭据及连续上报通过，可继续小范围试用。 |
| `Failed` | 本次来源、连接、归属、指标或时间检查未通过。 |
| `Cancelled` | 用户取消了本次检查。 |
| `Checking` | 检查尚未完成；意外结束后不会显示为通过。 |

通过结果与计划、只读来源和所选 Agent 归档指纹绑定。界面只把 10 分钟内且来源未变的结果标为“最近核验通过”，不承诺之后持续健康。每次检查仍须手动发起，没有新增常驻轮询、自动切换或自动停用旧服务。

## 验证结果

- .NET 核心主回归通过 1842 项断言；之后针对同机回环、端点差异及节点归档身份补充测试，最终接入专项通过 63 项。
- Linux 受管生命周期通过 24 项临时文件系统测试，服务及账号命令均为模拟。
- 服务端全套 Go 回归 694 项通过，1 项保留的转储测试跳过；关键包竞争检测 44 项通过，依赖缓存完整性核对通过。
- 真正的回环 HTTPS 测试使用测试专用 CA：可信链及正确主机名通过，错误主机名和不受信任颁发者被拒绝；失败 TLS 请求不会发送应用层凭据。未修改系统证书库。
- 原生隐藏表单通过旧主机名保护、计划／指引保存、范围切换保留编辑、只列已安装 Agent、未保存改动不写入、缺少连接阻止执行、关闭不提交任务等回归。既有只读监测页继续回归。
- 一次性 QEMU/KVM Debian 12 和 13 均使用先前已校验的监控支线 M2驱动及 RC2 实际附件建立旧安装，再升级 RC3：新增身份、原 Agent 凭据核验、原 Agent 文件不改写、真实上报推进、取消恢复、组件恢复和重启后身份稳定均通过。旧监控替身文件、数据和进程不变。

虚拟机使用临时磁盘、回环 SSH，以及文件标记／DMI 双重校验。它们不等同于生产迁移或真实 Cloudflare 公网访问。Windows 主回归仍有符号链接权限及未提供 Reality／远端 Python 运行时的既有跳过项；初始构建的 NuGet 漏洞元数据源不可达，未将编译成功当作新一次在线依赖安全审计。
