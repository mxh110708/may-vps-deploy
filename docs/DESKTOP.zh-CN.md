# Windows 桌面版

v0.9.9 采用 WinUI 3 + C#/.NET 桌面架构；此前 WPF 原生入口的 v0.7.0 发行已撤销。这里描述正式安装版和便携包的使用方式；发布不代表已经安装或连接生产。

部署开始后，当前主页面直接显示逐项计划与状态、耗时及当前操作，保留已完成、正在进行和待完成步骤；失败或取消单独标记，结束后保留结果。配置设计节点左侧提供拖动手柄，调整顺序后重新生成并校验；生成与导出页解释下一步和禁用原因。已有实例可从“添加协议”和各监控组件的“安装”入口追加安装，也可从“部署 → 已有实例追加安装”选择对象。详见[追加安装与部署过程](COMPONENT-INSTALLATION-2026-10-08.zh-CN.md)。

v0.9.6 修正普通 Windows 账号准备管理密钥时的权限失败，保留原始私钥和中断时已生成的管理密钥。本地密钥准备先于远端写入；此前仅系统审计失败且无待恢复事务的实例可直接继续草稿。如果已有待恢复部署基线，更新后选择“实例 → 核对恢复状态”，使用当前原 SSH 密码或私钥核对，明确确认恢复部署前基线；恢复完成后再“继续部署”。不要删除归档或绕过事务记录。任务结束会自动刷新最新状态。

本版配置设计采用两个独立生成目标，新增四类字号、多用途组合与独立网络调优。详细流程和验证边界见 [v0.9.0 桌面调整说明](DESKTOP-ADJUSTMENTS-2026-10-07.zh-CN.md)。桌面发行不再同步旧命令行使用目录。

v0.9.1 修正了更新检查结束后的状态提示，增加独立更新弹窗，在同一窗口显示 GitHub 更新内容、下载与 SHA-256 校验进度，显示安装进度窗口，并调整新安装的默认路径及“关于”页图标。这些行为在安装或升级到 v0.9.1 后生效；从旧版发起的首次升级仍由旧版更新器执行。

## 启动与环境

安装 EXE 默认目录为 `C:\Programs\May VPS Deploy`，仍按当前用户安装，也可选择其他可写目录。已有安装通过原目录升级，保留原位置和私人数据，不自动搬迁。支持 Windows 10 2004 及以上、Windows 11 amd64；从桌面或开始菜单打开，也可双击应用目录的 `May-VPS-Deploy.exe`。便携 ZIP 解压后直接运行 EXE。

应用内置 .NET 与 WinUI 3，SSH.NET 直接负责 SSH/SFTP，不加载 PowerShell 或 WPF。Python 3.13.16 与 ruamel.yaml 0.18.10 仅用于现有配置的专用转换，不驱动界面或运维任务。运行不修改全局 PATH，不安装 SSH 服务。

应用、窗口、安装包和卸载入口统一采用蓝、绿、暖金三块平面的图标。透明背景适配深浅桌面，多种尺寸用于任务栏、快捷方式和文件列表。设计与可编辑母版见 [图标说明](../assets/gui/ICON.zh-CN.md)。

源码构建使用 .NET SDK 10.0.400；打包脚本需要 PowerShell 7.4+。原 `Start-VPSDeploy.ps1` 和 `Start-VPSDeploy.Cli.cmd` 保留成熟命令行；其环境要求仍按旧文档。源码目录未构建 EXE 时，默认启动文件不会调用旧 WPF 界面。

## 使用逻辑

| 页面 | 使用方式 |
|---|---|
| 概述 | 查看本地实例与方案，进入部署、接入或配置设计 |
| 实例 | 选定对象后进行只读检查、维护、恢复或退役 |
| 部署 | 新机部署、首次接入或已有实例追加安装，审阅后在主页面逐步显示执行结果 |
| 配置设计 | 点亮 sing-box / Clash 目标，编辑节点与连接，校验并导出所选文件 |
| 网络调优 | 落地机 fq＋BBR；入口机自动采集、生成建议、应用后复测，并可安排一次晚高峰补测 |
| 记录 | 查看近期结果，逐条删除或清空列表，处理未完成的配置导出 |
| 设置 | 外观、字体、四类字号、窗口启动与关闭方式、检查更新、更新代理和数据位置 |

导航和填写表单不连接服务器。部署中的证书、IPv6 专用用户与监控设置按用途显示，额外设置默认折叠。已有 VPS 接入只读识别受支持配置，保留当前 SSH 认证、端口与防火墙；未知布局停止。

实例选择框收起时滚轮只滚动页面，不更换实例。代理核心升级明确选择 Xray（Reality）、sing-box（AnyTLS）或 sing-box（Shadowsocks）的服务实例，显示归档版本与应用支持的固定目标版本。监控与访问分成 Komari Agent、Komari 主控、Cloudflare Tunnel 三个独立入口，未纳管的组件不能维护；主控备份与恢复只包含主控程序及数据。任务记录支持逐条删除和全部清空，时间转换为本机时区；清理列表不会清理归档、备份或真实恢复事务。详见 [维护与记录调整](MAINTENANCE-ADJUSTMENTS-2026-10-08.zh-CN.md)。

服务商和实例名称会联动生成默认节点名；修改后保留自定义名称，清空后重新生成。审阅计划用可滚动分组展示对象、SSH、协议端口/核心、组件、防火墙、执行顺序、本地归档和验收，区分计划与实际检查。首次身份确认在正式 SSH 握手前独立完成，可比较服务商控制台取得的参考指纹；不提供参考时需明确首次信任，不代表已独立核验。

首次只读连接或审计失败时保留草稿，显示原因、阶段、错误代码及下一步，实例页提供继续部署/接入。继续使用已保存参数，不静默替换为新填写的表单。未确认写入优先核对恢复状态，不直接续作。实例页的“删除实例”审阅并删除该实例的全部本地受管文件；远端服务、源私钥、外部配置、其他实例、全局身份/历史/设置保留。运行中、存在未确认事务或审阅后材料改变时阻止删除。详情见 [部署体验修正](DEPLOYMENT-FIXES-2026-10-08.zh-CN.md)。

界面提供深色与浅色模式，在“设置 → 外观”切换并记住选择。深色使用蓝灰背景和浅蓝主按钮；浅色使用白色主区域、浅灰蓝卡片、深蓝侧栏和蓝色主按钮，往返切换保持正确状态色。标题、功能文字、注释说明、统计数值各提供大、中、小字号；说明中档为 14。设置与实例维护采用横向条目；部署表单在宽窗口并排显示，在窄窗口改为单列。“审阅计划”和配置设计“审阅并导出”固定在窗口底部，不随内容滚走。生成、校验与导出按状态启用。

配置设计按目标、节点、连接与分组、生成与导出四步组织。sing-box 和 Clash 两个卡片独立点亮，点亮两个就都生成。取消新建不保存空方案；退出编辑可保存或放弃修改；删除只清理本地方案和明确归属的候选，保留外部输出与恢复记录。节点使用左侧手柄拖动排序，或保留的上下按钮移动；生成、校验后填写所有所选目标的导出位置，再审阅并导出。修改节点或连接会使旧候选失效。

初次多用途部署选择默认入口；已有实例追加入口要求独立端口，可以与已有入口共存。追加安装只处理新组件及必要的证书和防火墙增量，不重放 SSH、基础系统或网络调优；有待恢复事务时先核对恢复。部署与接入不自动调优，在独立网络页面选择已有实例后再手动执行。

执行前生成不可变审阅快照，执行时再核对表单与归档摘要。一个窗口只执行一项后台任务；任务期间暂停表单编辑。密码、私钥口令与 Token 使用隐藏输入框，不进入任务记录。

取消或关闭窗口会等待远端当前写入步骤结束，再进入安全恢复边界。连接丢失不代表操作未发生；事务身份不符时停止，结果不明时记录待恢复，禁止盲目重放。用户明确跳过的协议验收写成未完成，不计为通过。健康任务成功仅表示证据读取完成。

协议恢复仅恢复协议程序、文件和服务，不覆盖 SSH、网络、防火墙或监控。网络调优保存并恢复受管参数文件、运行值和实际队列，不要求填写 RTT；细节见[网络调优](NETWORK-TUNING.zh-CN.md)。主控操作仅使用主控专用备份，不自动处理 Tunnel；主控整套卸载未开放。已安装协议可管理状态，未安装组件通过实例页“追加安装”进入。

## 数据目录

默认私人归档仍为 `<应用目录>/private`。设置中的“私人归档”显示当前实际路径，点击“修改目录”选择一个空的独立本地文件夹，审阅文件数量和目标后迁移。迁移包含实例、密钥、受保护凭据、方案、字体和任务记录；应用文件与 `config/*.local.json` 保留在安装目录。路径、方案来源指纹和归档校验清单同步更新，已有候选必须重新生成与校验。迁移拒绝非空目标、嵌套目录、链接、只读材料和未完成的恢复事务；复制成功后才启用新目录并移除旧副本。自定义目录不可用时停止启动，不回退到空归档。

安装目录的 `archive-location.private.json` 只记录所选目录及归属标识，属于本地文件，更新保留、发行包不携带。归档目录中的 `.may-private-directory.json` 用于确认卸载删除的范围。卸载选择“保留”时同时保留定位设置和自定义归档；选择“彻底删除”时校验归属并删除该归档目录，保留其父目录中的其他文件。凭据仍由原 Windows 账号保护，改目录不等于转换账号或操作系统。

配置设计的受管节点选择提供“全选／取消全选”，只作用于当前显示的可添加节点；已在方案中的节点不会重复添加。Reality 的备用端口连接默认隐藏，可启用“显示备用入口”后选择，显示为“备用入口”。这是真实备用连接，不是导入了备份文件；导出保留原节点名以兼容现有配置。

```text
<应用目录>/
├─ May-VPS-Deploy.exe 与 .NET/WinUI 库
├─ runtime/python/                  专用配置转换环境
├─ app-helpers/                     安装校验与更新辅助程序
├─ config/*.local.json              原有本机文件，原样保留
└─ private/
   ├─ instances/<服务商>/<实例>/MXH-VPS-Deploy/
   │  ├─ deployment-plan.json
   │  ├─ deployment-state.json
   │  ├─ secrets.dotnet.private.json
   │  ├─ operation-pending.dotnet.json
   │  ├─ ssh/ 与 server-configs/
   │  └─ maintenance-backups/ 与 komari-backups/
   ├─ client-schemes/               当前 Windows 用户加密方案
   ├─ client-candidates/            私人候选
   ├─ client-publish/               所选配置导出及恢复材料
   ├─ desktop-settings.json
   ├─ ssh-hosts.dotnet.json          核对过的主机身份
   ├─ instance-locks/               跨任务与删除操作的共享协调锁
   └─ task-history.dotnet.json      最近 120 项任务元数据
```

桌面端不扫描或搬迁命令行实例目录，不提供旧归档导入 UI。旧归档、旧驱动未完成任务及跨账号/跨系统凭据保护由维护者离线转换并核对。离线归档中的监控历史记录提供只读“核对并纳管”；健康检查补齐当前组件状态和缺失 Agent 连接材料后再开放维护，详见[监控归档补充](MONITORING-ARCHIVE-SUPPLEMENT.zh-CN.md)。原有 local.json 原样保留，不代表新界面已经采用其中所有旧偏好。

SSH 服务商源私钥不修改；只有新生成的管理私钥和本应用建立的副本设置权限。首次 SSH 主机连接支持独立核对指纹，或由使用者明确接受首次身份；已信任主机的密钥变化时拒绝连接，不直接覆盖信任。

客户端外部权威文件保留现有位置；导出到 Clash Verge AppData 会被拒绝。只要求所选目标的路径；浏览可选择新文件或已有文件，不提前创建或改写目标，审阅后才写入。双文件不能跨文件原子替换：先备份、记录阶段，再逐份替换；单/双文件恢复均逐项核对摘要，遇到外部修改则停止。

## 窗口启动与关闭

默认以 1280 × 850 的逻辑尺寸在主屏幕工作区中央打开，小屏幕会按可用空间缩小。在“设置 → 窗口启动”开启“记住关闭时的窗口位置和大小”，以后恢复关闭时正常窗口的位置和尺寸；关闭此选项会清除旧记忆，下次仍以默认大小居中打开。

记忆会按当前显示缩放调整，位置或尺寸超出工作区时限制到可见区域；原显示器不可用或记忆数据无效时使用主屏幕默认居中布局。最小化时读取正常窗口的位置，后台测试窗口的屏幕外位置不会保存。

“关闭设置”可选择最小到托盘或关闭应用。关闭到托盘时任务继续，托盘菜单可重新打开或退出；直接退出时，正在执行的任务先在安全边界结束。

## 更新与卸载

自动检查默认关闭，启用后启动时查询本项目正式 GitHub Release；实际安装仍由用户确认。手动“检查更新”使用相同机制。默认更新代理为本机混合代理，可在设置中编辑或清空；不改系统代理或 TUN。

检查完成后，底部显示“已是最新版本”或新版本信息；失败、取消及暂缓安装均结束忙碌状态。发现新版打开独立更新弹窗，展示当前/新版版本号及 GitHub Release 更新内容；点击“下载并安装”后，同一弹窗显示百分比和已下载/总大小，再按读取并计算 SHA-256 的实际字节显示校验进度。准备期间使用不定进度条，下载失败可在弹窗中重试。取消只清理本次尚未启动的更新暂存。关闭应用后显示安装进度窗口，安装错误正常提示，完成后重新打开应用。“关于”条目使用与应用相同的图标。

安装版下载正式安装 EXE、逐文件清单和 SHA-256，核对 GitHub 资产摘要、大小和校验清单，等待窗口退出后原位安装并自动重新打开。无需卸载重装。安装器复核当前受管文件，用户修改、未受管路径冲突或篡改会阻止更新；私人归档、local.json、导入字体、外观偏好与缓存保留。下载失败或取消会清理本次尚未启动的暂存；安装已经开始而未完成时保留必要材料。便携包暂不提供自动原位更新，正式安装包是推荐交付方式。

卸载提供“保留私人归档和本地配置”与“彻底删除应用及本地数据”两种选择。彻底删除仅限选定安装目录；外部权威、旧实例目录和服务器不在范围。发现链接时拒绝递归删除。保留卸载后重新安装可以继续读取本账号的数据。

## 开发验证

```powershell
dotnet restore .\desktop\May.VpsDeploy.Tests\May.VpsDeploy.Tests.csproj --locked-mode
dotnet run --project .\desktop\May.VpsDeploy.Tests -c Release --no-restore -- $PWD
pwsh -NoProfile -File .\Start-VPSDeploy.ps1 -Mode ValidateProject
pwsh -NoProfile -File .\scripts\New-VpsReleasePackage.ps1 -Development -Destination '<预览目录>'
```

构建锁定 .NET、WinUI 与 SSH.NET 包；运行环境、专用 Python/YAML 和 Inno 资产按固定目录与摘要核对。实际运行七个 WinUI 页面和输入对话框后才允许生成安装包。预览名带 `ui-preview`，不会作为正式自动更新资产。

安装生命周期回归使用无快捷方式、无卸载注册项的 QA 包，在隔离目录实际点击 WinUI 检查更新及确认按钮，经过下载、校验、真实父进程退出、原位安装和新版 EXE 自动重启，验证私人归档、本地配置、自定义字体和外观保留；另检查本地修改保护、保留卸载、重装和彻底删除。QA 更新传输仅在明确标记的测试安装包中启用，正式应用使用 GitHub HTTPS 和所选更新代理。共享核心 CI 覆盖 Windows/Linux/macOS；编译和模拟通过不等于已交付 Mac/Linux 桌面，也不代替生产 VPS 验收。

验证范围根据改动确定。仅在更新功能、安装器或发布结构发生变化时专项验证更新，不因普通界面改动重复安装生命周期或线上附件下载。

提供两套内置界面字体：原版（Route 风格：Schibsted Grotesk，中文系统回退）和霞鹜文楷（完整原始 Regular，1.522），初始默认保持原版，侧栏品牌保留 Source Serif 4。在“设置 → 外观 → 界面字体”可自由切换这两套字体或已导入的自定义字体。点击“导入字体”选择 TTF/OTF（单文件不超过 64 MiB）；校验后按内容哈希保存到应用的 `private/fonts/`，重复导入不产生副本，切换立即作用于页面和弹窗并记住选择。文件丢失或被修改时回退到原版字体并提示重新导入。字体只供应用使用，不向系统安装；升级和保留数据卸载会保留，彻底删除会一并移除。所有内置字体保留完整 OFL 许可证。配色与导航结合 Route 和 Windows 设置界面。
