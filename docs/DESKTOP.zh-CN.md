# Windows 桌面版导航

当前产品为 WinUI 3 + C#/.NET 的 May VPS Deploy。桌面安装包自带运行依赖，PowerShell 菜单及旧 WPF 源码不是其运行入口。当前文档基线为 v0.9.38。

请按任务进入完整手册：

| 任务 | 入口 |
| --- | --- |
| 安装、首次连接、新部署、接入和追加组件 | [桌面使用手册](USER-GUIDE.zh-CN.md) |
| 方案、节点、分流、导出、转发与多跳 | [客户端配置与线路](CLIENT-AND-LINES.zh-CN.md) |
| 更新、备份、确认不明、恢复与退役 | [维护手册](MAINTENANCE.zh-CN.md) |
| Server、Agent、HTTPS、主题和告警 | [监控运维](MONITOR-OPERATIONS.zh-CN.md) |
| 编译和测试 | [开发与验证](DEVELOPMENT.zh-CN.md) |

安装位置可选择，已有更新保留原目录；私人材料、任务记录、实例删除和远端卸载有不同范围。界面状态和恢复规则以使用／维护手册为准，不能照历史版本的截图操作。

早期 v0.9.x 的界面与验收变化保存在[历史索引](HISTORY.md)，并非需要逐个执行的升级步骤。
