## 使用流程

1. 选择「监测 → 配置只读连接」，填写已部署 May Monitor 的 HTTPS 基地址。没有服务端时不自动安装或联系公网。
2. 每个本地实例明确填写服务端已有节点的 UUID；留空的实例不接入。不按名称、地区、服务器 IP 或已保存的 Agent Token 猜测身份。
3. 可粘贴已有的专用只读令牌，或点击「生成新只读令牌」。不接受管理员 API Key、初始化密钥或 Agent Token。
4. 「预览服务端授权配置」只生成 SHA-256 摘要、节点 UUID 列表和 30 天到期时间，不包含原始令牌。由服务端维护者在独立环境配置中应用，并按既有服务管理流程重启服务；本页不会执行远端写操作。
5. 保存后点击「刷新监测」。保存和打开页面本身不发出监测请求。
6. 需要持续查看时，主动开启「此页可见时每 30 秒刷新」。切换页面、最小化、关闭到托盘或退出会暂停读取；重新进入页面默认关闭自动刷新。读取中的请求可直接取消。

无效输入或保存失败会保留对话框和草稿。取消配置不写文件，取消移除也不改变连接。重新预览只改变待应用的授权文本，不能据此认为服务端有效期已经续期。

## 显示与数据口径

每个绑定实例独立纵向展示，列表随实例数量延长并由原有页面滚动。包括本地实例名称、监测 UUID、在线状态、最近上报时间、CPU 百分比、内存使用／总量、上传／下载速率和累计计数。字节使用二进制单位，速率单位为每秒；累计计数沿用 Agent 上报语义，不宣称是服务商账单或自部署日起的永久累计。

| 状态 | 含义 |
| --- | --- |
| 尚未读取 | 本机没有取得当前连接的快照 |
| 未返回节点 | 该 UUID 未被本次授权返回，或尚未在服务端注册；不据此判定离线 |
| 尚无上报 | 节点存在，但没有可用的上报时间 |
| 在线 | 服务端存在有效连接／在线保活，指标与快照均未过期 |
| 在线 · 上报已过期 | 服务端仍报告在线，但最新指标超过 90 秒 |
| 在线 · 指标无效 | 有在线状态，但该次指标不符合范围约束；不填成零负载 |
| 离线 · 保留最近上报 | 服务端已无有效在线状态，旧指标仅作最近记录 |
| 读取失败或快照过期 | 获取失败或桌面快照超过 90 秒，不将连接问题误记成全部节点离线 |
| 节点时间异常 | 节点上报时间明显在本机未来，需要核对时间同步 |

快照携带服务端生成时间，客户端拒绝与本机相差超过两分钟的响应。没有跨时钟自动校正或延迟学习；异常时间必须显式核对。离线、过期或读取失败时，保留的数据都有对应状态和时间，不代表当前测量结果。

手动读取后页面停留时，状态也会到期更新。界面只在下一次状态边界安排一次性定时器，不为此额外访问服务器；失效后停止，页面隐藏时暂停，恢复时重新核对时间。

## 凭据、数据和网络边界

- 服务端接口为 `GET /api/integration/v1/snapshot`，仅接收请求头里的 `Bearer may_read_…` 专用令牌。不支持查询参数、请求正文或写入方法。
- 默认完全关闭。启用需要同时配置令牌 SHA-256、明确节点 UUID 和有效期；最多 100 个节点，不能通配、重复或省略。有效期必须在未来且不超过 90 天。
- 令牌由密码学随机数生成。`may_read_` 请求头命名空间不提升为管理员或 Agent 身份，即使误填入普通管理员 Key 配置也不能借此进入管理 API／RPC。
- 服务端只从数据库投影已授权 UUID，再复制这些节点的最新指标和在线状态，不扫描复制所有 Agent 历史。响应不包含 Agent Token、登录信息、IP、节点名称、备注、计费、配置、任务或文件内容。
- 响应禁止缓存。客户端限制完整读取时限为 10 秒、正文为 256 KiB、结构深度为 12、节点为 100 个；未知模式、重复 UUID、无效指标、登录 HTML、压缩响应和错误返回均不作为成功快照。
- TLS 使用系统正常证书验证。客户端不跟随重定向、不携带浏览器 Cookie，也不复用应用更新代理；HTTP 仅用于本机回环地址。错误提示不回显响应正文或令牌。
- 私人连接保存在私人归档根下的 `monitor-read.private.json`，使用现有 Windows DPAPI 保护，不写入普通桌面设置、实例目录、导出配置或任务记录。私人归档整体迁移会一起移动该文件。
- 同时最多一项读取。页面或连接变化时旧响应不能覆盖新连接；绑定实例被移除后停止读取，要求重新编辑绑定。
- 「移除本机连接」只删除该加密文件及内存快照。真正撤销在服务端移除／轮换摘要并重启服务完成；桌面只读令牌没有撤销或创建管理凭据的权限。

具体服务端配置、请求与撤销方式见 May Monitor 服务端的 `docs/READ-ONLY-INTEGRATION.zh-CN.md`。完整管理员凭据没有因本轮变成低权限凭据，不能复用。
