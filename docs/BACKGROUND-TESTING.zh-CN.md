# 应用后台实测接口（B 方案）

v0.9.7 提供独立的原生后台测试实例。测试指令在应用内部操作实际 WinUI 表单、按钮和对话框，触发正常的校验、审阅、凭据输入、任务协调器和部署流程。测试进程使用同一版本的运维核心与 Bash 模块。

测试窗口位于屏幕外，不显示在任务切换器中，禁止窗口激活；输入通过本进程控件接口完成。测试期间采集窗口激活事件与前台采样，出现激活立即拒绝后续测试指令。测试启动脚本设置较低的进程优先级。测试不需要虚拟机、ADB 或电脑操控。

## 会话与归档

普通启动只提供正常应用功能。测试模式需要显式的 `--test-session` 会话清单，创建新的独立目录、匹配的隔离标记和随机会话凭据。正式应用与测试实例使用不同的单实例锁。

每轮测试单独保存配置、实例、受保护凭据、任务、导出和报告。启动脚本仅复制公开资产与运行环境，排除私人及本地配置。测试工作区与其父级必须是普通目录，私人归档不能重定向到正式数据。

SSH 默认没有可连接目标。联网测试需要在会话中逐个列出明确的测试 IP 和 SSH 端口；连接前核对该白名单及测试目录内的密钥。导出、文件参数、凭据引用和测试图像也限制在本轮目录。白名单是会话的执行边界，运行远端安装或清理仍需目标所有者授权。

空白系统部署会生成主、救援 SSH 端口。专用测试机可在启动脚本显式选择 `AllowManagementPortTransition`：正常审阅确认后，仅加入同一已列明初始 SSH 目标的两个计划管理端口，并保存私人授权证据。其他主机、初始端口及无关端口仍拒绝连接；派生端口不能再次扩大目标范围。默认关闭此选项，未列明管理端口的部署在审阅后、远端操作前拒绝开始。此选项只调整测试会话的连接范围，不配置服务商安全组，也不跳过应用的身份核对与访问验收。

## 专用测试机的中断注入

v0.9.14 增加显式的 `AllowTransportFaults` 选项。它仅用于已经授权的专用测试机、独立归档和非空目标白名单；普通启动和默认后台会话不读取故障文件，合成界面回归也不能开启。

在本轮 `test-secrets/transport-fault.private.json` 放置以下参数，可在指定步骤的一次调用中关闭本会话自己的 SSH 连接，或退出自己的测试进程。它不修改电脑网络、防火墙、代理或其他应用。

```json
{
  "SchemaVersion": 1,
  "Id": "0123456789abcdef0123456789abcdef",
  "Asset": "xray-install.sh",
  "Action": "ExitAfter"
}
```

`Id` 每次使用新的 GUID（N 格式）。步骤只允许 `audit.sh`、`ssh-transition.sh`、`nftables-apply.sh`、`xray-install.sh`、`deployment-snapshot-delete.sh` 和 v0.9.15 增加的 `network-apply.sh`；动作只允许 `DisconnectBefore`、`DisconnectAfter`、`ExitAfter`。后两者在远端成功返回后、应用确认该步骤之前制造中断，验证丢失确认时的恢复。

故障先保存消费标记，重新打开同一测试会话不会再次注入。请求记录只包含步骤名、时间和请求/返回阶段，不记录载荷或凭据。中断后通过实例页正常核对恢复状态；恢复或者明确开始新部署之前，不能重发原变更。测试进程退出后需重新建立已审阅管理端口的明确白名单，不能扩大到其他目标。

## 自动原生回归

在仓库的 PowerShell 7.4+ 中运行，使用全新的测试目录：

```powershell
./tests/Test-BackgroundNative.ps1 `
  -ApplicationDirectory '<已构建或安装的应用目录>' `
  -FixtureRoot '<新的独立测试目录>' `
  -ProjectRoot $PWD `
  -PythonRuntimeDirectory '<该应用目录>/runtime/python'
```

该回归通过真实按钮与表单测试命名、条件监控字段、无效计划拒绝、目标选择、节点输入、生成与核心校验、双格式导出、方案保存和退出，以及已有原生页面回归。使用合成节点，SSH 白名单为空。提供内置 Python 后执行真实配置生成和固定客户端核心校验。报告明确区分通过、跳过和未验证。

Windows 安装器 CI 的原有单次生命周期任务也执行这项后台回归；不为每个矩阵重复增加安装测试。

## 按界面状态驱动测试

`scripts/Start-VpsBackgroundTest.ps1` 创建会话并启动原生进程，返回清单、进程号和报告目录。源码工作区可通过 `PublicAssetRoot` 指定公开资产；安装包默认使用安装目录中的资产。合成回归使用 `SyntheticFixture`，联网测试使用经授权的 `AllowedEndpoints`。需要的测试实例和凭据由测试准备流程复制到独立目录。

本机管道只允许当前用户，使用随机名称、会话 Token 和请求 ID 校验；重复请求拒绝执行。每次连接传输一条有大小、深度和读取时间上限的 JSON 指令。接口提供以下命令：

| 命令 | 用途 |
|---|---|
| `ui.read` | 读取当前页面、忙碌状态、对话框、通知及可见控件 |
| `ui.set` | 设置实际文本框，触发正常文本变更事件 |
| `ui.choose` | 选择实际下拉选项，触发选择事件 |
| `ui.toggle` | 设置实际勾选或开关状态 |
| `ui.secret` | 从 `test-secrets` 下的文件引用填入密码框 |
| `ui.invoke` | 调用实际按钮的原生 Invoke 接口，触发正常点击处理 |
| `ui.scroll` | 滚动测试应用自身的内容容器 |
| `ui.drag` | 调用当前节点手柄的按下、移动、释放与取消处理，可分阶段检查拖动图像 |
| `ui.capture` | 将应用自身的 XAML 页面或当前对话框渲染成 PNG |
| `network.schedule.check` | 检查应用自己的到期网络测量计划，使用真实调度流程；不修改系统时钟 |
| `suite.run` / `suite.status` | 启动并读取合成归档专用的原生页面回归 |
| `session.stop` | 在安全边界取消任务并关闭本轮应用 |

操作优先使用 `ui.read` 返回的控件 ID；名称重复或控件失效时必须重新读取。禁用按钮不接受调用。指令被接受只表示事件已触发，异步任务应继续读取真实界面和结果，不能把接受当成成功。

```powershell
$ui = ./scripts/Invoke-VpsBackgroundTest.ps1 `
  -SessionManifest '<测试目录>/test-session.private.json' -Command 'ui.read'

./scripts/Invoke-VpsBackgroundTest.ps1 `
  -SessionManifest '<测试目录>/test-session.private.json' `
  -Command 'ui.secret' -Arguments @{id='<密码框 ID>';reference='agent.txt'}
```

密码框只返回是否已填写，不返回密码；管道审计记录只包含时间、请求 ID、命令和安全结果，不记录参数、控件值或凭据。界面快照、导出和远端证据可能包含私人实例资料，应按私人归档保管。

同一 EXE 还提供无需 PowerShell 的客户端：

```text
May-VPS-Deploy.exe --test-command <会话清单> <请求 JSON 文件> <响应 JSON 文件>
```

请求文件包含 `command` 和 `arguments`；客户端读取会话认证信息，在进入 WinUI 前完成管道调用。响应文件位于本轮目录，保留协议结果；退出码 0 表示指令接受、2 表示明确拒绝、1 表示客户端未完成。测试模式不提供任意命令执行接口。

## 证据与实际边界

`test-artifacts` 保存命令审计、原生流程报告、应用图像和关闭时的焦点记录。远端测试应保存所选组件、实际结果、恢复阶段及清理证明，公开报告去除地址、端口、Token、凭据和归档身份。

`ui.drag` 以当前手柄控件 ID 和插入位置调用原生路由事件共用的处理器，检查实际控件几何、整行预览与插入提示，不注入系统鼠标。默认一次完成；也可使用 `phase=begin`、`move`、`end`、`cancel` 分阶段执行，在移动后用 `ui.capture` 核对图像。开始使用手柄 ID，移动或释放使用 `insertion`，取消保留顺序；导航后旧手柄失效。该接口不模拟操作系统的指针捕获。

`window.close` 向测试实例自己的窗口发送关闭消息，经过正常关闭设置和未保存方案检查；`window.restore` 恢复测试实例且不激活前台。托盘图标创建和移除使用真实 Windows Shell 接口，系统托盘菜单点击仍须单独验收。

联网结果及剩余项目见 [v0.9.13 IPv6 与恢复补测](TESTING-0.9.13.zh-CN.md)、[v0.9.12 空白系统部署与重启实测](TESTING-0.9.12.zh-CN.md)、[v0.9.11 拖动修正与补充实测](TESTING-0.9.11.zh-CN.md)、[v0.9.10 Tunnel 实测与排序回归](TESTING-0.9.10.zh-CN.md)、[v0.9.9 AnyTLS/ECH 实测记录](TESTING-0.9.9.zh-CN.md)、[v0.9.8 组合追加记录](TESTING-0.9.8.zh-CN.md)与 [v0.9.7 实测记录](TESTING-0.9.7.zh-CN.md)。Tunnel 使用用户为测试创建的专属 Token 与路由；没有复用正式监控 Tunnel。

Tunnel 公开访问验证可通过实例页的正常控件调用，检查实际 VPS 的连接器、本机主控和公开 HTTPS 接口并保存结果。该检查不接收管理员凭据、不修改 Cloudflare 路由或重启服务；连接成功与公开路由验证分别记录。

屏幕外的原生渲染可以检查页面和对话框内容；物理拖动、滚轮命中、系统文件选择器、UAC 与多显示器体验仍需单独实测。后台模式保护日常工作的鼠标和焦点，同时保留这些测试边界。
