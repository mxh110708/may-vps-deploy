## 全局边界

| 边界 | 核对结果 |
|---|---|
| 界面与业务 | WinUI 收集参数、审阅并展示状态；Core 验证用途、对象、版本、范围与来源。SSH、核心校验和测量由 Infrastructure 适配，Windows 凭据、托盘和更新隔离在 Windows 层。 |
| 部署与追加安装 | 首次部署先建立独立基线；已纳管实例用本轮组件快照。安装的具体版本与发行资产在审阅前锁定，追加安装保留既有组件。 |
| 未确认结果 | 持久化事务身份与本地阶段。连接中断或提交确认丢失先查询身份和状态；不能凭一次失败自动重放远端变更。 |
| 恢复范围 | 协议恢复不覆盖监控、网络或防火墙；主控恢复不替换无关 Tunnel；网络恢复只涉及已核对参数、队列和文件；内核安装、激活及回退独立审阅。 |
| 来源与导出 | 私人归档提供受管节点来源；候选生成、固定核心校验、目标审阅和导出分别执行。修改来源、凭据、节点或目标使原审阅失效；本地导出事务与远端维护分离。 |
| 调度及关闭 | 自动补测等待其他任务及弹窗，不能交错任务；托盘保留任务，真正退出在安全边界处理。窗口偏好及归档迁移有独立本地校验。 |
| 新旧控制端 | 远端脚本及生成器共用；原生 EXE 不加载历史 WPF/PowerShell 向导。传统 CLI 的单角色、固定端口说明已在模块文档明确标注。 |

## 验证与兼容限制

本轮未向 VPS 写入，也未重放已完成的部署、证书签发或内核重启。上述服务/恢复夹具证明本轮代码分支和文件范围，不能充当新的真实网络、systemd 调度或启动结果。既有真实 VPS、令牌轮换、Komari 迁移和内核验收见此前版本记录。

缺少所有权身份的历史活动防火墙快照继续保留，拒绝自动清空或覆盖；未知状态需先核对。普通已完成归档与受支持的旧配置方案保持可读。私人目录、独立配置和非测试 VPS 不因本轮验证改变。

全局鼠标、系统选择器及 UAC 操控保留一项未验证，遵守不占鼠标的要求；用户此前已确认实际鼠标排序正常。当前本机缺少直连 IPv6 条件，长期真实高峰/非高峰对比及未触发的极端故障仍不能记为通过。
