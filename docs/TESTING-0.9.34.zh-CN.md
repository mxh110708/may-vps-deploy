# v0.9.34 配置与链路扩展验证

本版整合前七轮源码，沿用现有安装身份和私人归档格式。GitHub 账号、实例凭据及现用 Route / Clash 系统代理不变，用户通过应用内更新自行安装。

## 功能范围

| 轮次 | 本版内容 |
| --- | --- |
| 一 | 外部分享链接导入、连接图、删除影响和按需线路诊断 |
| 二 | 输出筛选、命名排序、分客户端能力报告、手动订阅刷新及差异审阅 |
| 三 | AnyTLS 的服务器固定 SS / SS2022 落地、出口验收及组件恢复 |
| 四 | Reality 主备双栈固定落地、来源变化提示、升级／轮换／恢复保留链路 |
| 五 | 有序 TCP 完整域名、后缀和 CIDR 分流，以及明确直连和阻断 |
| 六 | 一个默认与最多七个附加落地，具名规则、逐项 TLS / 出口验收及维护恢复 |
| 七 | 可选择的分享链接列表，遵循输出规则，严格保留原参数，支持复制和新文件保存 |

各轮详细边界从[实施索引](FLYX-DESIGN-REVIEW-2026-10-20.zh-CN.md)进入。服务器 UDP 保持默认落地，不提供逐目标 UDP 分流；分享链接不携带客户端链路、分组、ECH 或服务器配置。在线订阅托管、独立端口转发、任意多入站及新协议没有在本版实现。

## 本地证据

- 完整 .NET 回归包含真实 Python 客户端生成、固定 Mihomo / sing-box 核心解析、真实 AnyTLS／Reality 本地回环和多落地 TLS 探针。第七轮专项 61 项断言通过，最终合计 1529 项。
- `Start-VPSDeploy.ps1 -Mode ValidateProject` 成功，主入口 911 项断言，以及交互 40、配置工作台 31、菜单 15、审计 60、PowerShell 启动 4、应用更新 50、旧 GUI 43 项。其余 Python / Bash 行为检查通过；没有重复运行其内部 `Run-Tests.ps1`。
- 前六轮已经完成各自的隐藏原生验证；服务器出站最新为 27 组。第七轮原生分享界面 11 组通过，覆盖禁止链路／ECH 降级、无凭据预览、复制选择、Base64、文件名与旧文件保护、预览过期和取消保护。
- 原生测试使用独立合成归档；分享复制进入测试接收器，未修改系统剪贴板。截图已检查，测试实例已关闭。退出证明记录 0 次窗口激活、0 次前台采样、无托盘、无全局输入、无未完成任务。
- Windows 缺少链接权限的既有 .NET 和 Bash 链接检查明确跳过；Linux CI 继续执行相应行为分支。本版把新增的出站和逐落地探针 Bash 测试加入 Linux 工作流。
- 首次远端检查在 Python 3.9 下发现测试夹具误用较新版本 `Path.write_text(newline=...)` 接口；已改用跨版本的 UTF-8 字节写入，保留 Bash LF。该修复限定测试文件，不改变产品功能，也没有取消最低版本检查。
- 构建使用固定依赖和锁文件。`NU1900` 表示本机构建时在线 NuGet 漏洞元数据不可达，不能把构建成功写成在线漏洞审计通过。本机没有可用 ShellCheck，Linux 工作流运行该检查。

这些证据来自合成归档、实际本地核心和模拟事务，没有连接或变更生产 VPS。端口监听、核心配置检查、回环成功和服务器逐落地出口检查均不能代替真实业务、远端白名单和公网网络验收。

## 正式分发

正式附件由干净的 main 源码生成，提供 Windows 安装 EXE、便携 ZIP、文件清单、SHA-256 清单及对应的 Google BBR v3 源码附件。打包会启动隔离的原生运行环境复核，确认 WinUI 3 和内置 .NET 加载，不执行用户应用的安装或更新。

最终提交的跨平台 .NET、Windows 客户端及隔离安装器、Linux 脚本检查状态以[GitHub Actions](https://github.com/mxh110708/may-vps-deploy/actions)为准；发行附件以[v0.9.34 Release](https://github.com/mxh110708/may-vps-deploy/releases/tag/v0.9.34)为准。测试和发布不授权自动替换用户本机的安装。
