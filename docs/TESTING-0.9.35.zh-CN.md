# v0.9.35 转发与客户端分流验证

本版在 v0.9.34 基础上整合第八轮独立 TCP 转发、第九轮独立 UDP 转发和第十轮 Shadowsocks／SS2022 UDP 验收，并包含待发布的校园、学术数据库与 Hugging Face 分流修复。

## 新功能与修复

- TCP 转发支持 IPv4／IPv6／双栈监听、来源白名单、启停移除，以及经转发的 TLS、SSH 或已保存代理验收。
- UDP 转发支持按来源和本地目的地址隔离的有界会话、超时、数量限制、双栈／跨族转发，空闲时按需退出。
- UDP 新增从已保存 Shadowsocks／SS2022 节点选择目标并进行真实加密 DNS 往返验收，补齐只有 DNS／回显目标可验收的限制；保存、维护与恢复仍分 TCP、UDP 组件管理。
- 校园入口明确 DIRECT 并配合本地 DNS；补齐研究平台、论文全文和认证链路，Hugging Face、Scholar、Colab、Kaggle 等归入 Academic Research，ML 开发工具归入 Developer Tools。ExistingAuthority 不会被通用生成器隐式接管。

各轮参数、流程、边界及回退方式见[第八轮](TCP-FORWARDING-ROUND-8-2026-10-21.zh-CN.md)、[第九轮](UDP-FORWARDING-ROUND-9-2026-10-21.zh-CN.md)、[第十轮](UDP-PROXY-ROUND-10-2026-10-23.zh-CN.md)和[学术分类审查](ACADEMIC-ROUTING-AUDIT-2026-10-23.zh-CN.md)。

## 本地验证

完整 .NET 回归 1732 项断言通过，新增代理测试使用真实固定核心及合成回环；验证多种加密方法、SS2022 身份链、双栈、错误凭据、不可达、取消、来源变化与组件范围回退。测试默认未配置的 Xray 运行分支另用现有固定资产执行专项，不把跳过计作通过。

真实 WinUI UDP 表单回归包含第十轮来源选择、缺失／非法参数、参数回填、审阅、保存回填与取消保护；界面截图检查及退出证明用于确认无窗口激活、无前台采样、无全局输入和未完成任务。

主项目入口 `ValidateProject`、固定双核心客户端兼容检查及公开材料检查用于正式构建前核对。Mihomo 与 sing-box 各执行 16 次学术和校园分流实际请求。Linux UDP 与 TCP 回环在临时网络命名空间执行，UDP 来源策略的非回环分支单独补测；没有改动现用 WSL 网络。

本机构建此前出现的 `NU1900` 表示 NuGet 在线漏洞元数据不可达，不代表已完成在线漏洞审计。Windows 缺少链接权限的测试明确跳过，相应 Unix CI 分支继续执行。真实 VPS、公网链路、服务商安全组、QUIC 及吞吐未在本次本地测试中验收。

## 正式分发

正式包从干净 main 源码构建，提供 Windows 安装 EXE、便携 ZIP、文件清单、SHA-256 清单及 Google BBR v3 对应源码。打包核对内核来源并启动隔离 WinUI／内置 .NET 运行环境复核；发布前检查实际包文件、版本及摘要，发布后核对公开附件和更新识别。

本次不安装用户应用、不修改实例私人归档、不连接或部署生产 VPS，不重载或切换现用系统代理。用户通过应用内更新自行安装。转发功能只有在用户后续明确审阅并执行对应实例操作后才应用到服务器。
