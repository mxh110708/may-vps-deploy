# 第十轮：UDP 转发的 Shadowsocks／SS2022 验收

本轮补齐第九轮的代理目标验收。它仍是一个明确 IP／端口的独立 UDP 转发组件，不创建跨实例多跳事务、隧道封装或新的代理服务。第八至第十轮随 v0.9.35 整合发行；本文区分实现与本地验证，不表示已在生产 VPS 部署。

## 使用流程

1. 先在配置设计中保存具有完整原生参数的 Shadowsocks／SS2022 节点。节点使用明确的非回环、非链路本地 IP，包含加密方法、端口和凭据。
2. 在实例的「管理 UDP 转发」中添加或编辑规则，验收方式选择「Shadowsocks／SS2022 代理 UDP」。
3. 选择已保存的来源，程序回填目标 IP 和端口；填写监听地址族、端口及允许来源。来源应包括控制电脑的相应公网地址，目标白名单应允许转发实例。
4. 核对代理出口查询的 DNS IP、UDP 端口、查询域名和 A／AAAA 类型。默认值用于一次有限验收，可按代理出口实际可访问的 DNS 修改。
5. 审阅并执行。规则保存会清空此组件的旧 UDP 会话；只有实际往返响应、资源摘要和管理连接均通过，任务才提交。

「只读检查已保存转发」使用已归档规则和当前有效的来源，不应用表单草稿、不重启转发器。来源已变化或被删除时，应明确重新选择并审阅，程序不会自动采用新凭据。停用规则保留参数但不发送探测。

## 如何证明走了 UDP 转发

控制端按需启动固定、校验过版本与摘要的 sing-box，仅监听一个回环 UDP 端口。它将 DNS 数据报按所选原生 Shadowsocks 参数加密，发送到本次转发监听地址；转发实例送往目标代理，代理向指定 DNS 发起查询，响应沿原路径返回。每次尝试使用新的 DNS 查询 ID，并核对问题名称、记录类型、响应标志、错误码、边界和有效答案。

临时配置只有一个 UDP 代理出站，没有 TCP、DIRECT 或系统代理回退；也不会在控制端直连所选 DNS。代理出口的 A／AAAA 查询类型与转发连接的 IPv4／IPv6 地址族分别填写，二者不混为一谈。双栈监听逐个完成实际响应检查，缺少任何一个地址族即拒绝提交。

每个代理检查最多 30 秒，其中最多三轮、每轮三秒响应等待；整次 UDP 验收继续受两分钟总预算约束。取消会终止正在运行的临时核心、等待进程退出并删除包含凭据的临时配置。输出管道用固定缓冲区丢弃，不将核心输出或代理密码写入普通日志。没有新增常驻监控、后台轮询或系统服务。

## 支持边界

- 六种现有方法：AES-128-GCM、AES-256-GCM、ChaCha20-IETF-Poly1305，以及 SS2022 的 BLAKE3 AES-128-GCM、AES-256-GCM、ChaCha20-Poly1305。实际核心检查不通过时停止，不能静默转换加密方法。
- SS2022 AES 两种方法另实测服务器密钥与用户密钥组成的身份链；原凭据保持不变。
- 额外客户端 detour、插件、特定接口绑定、复用及 UDP-over-TCP 目前不支持，不自动删除或转换这些参数。
- 成功证明该 DNS 请求经转发与所选代理取得了匹配响应，不证明最终出口 IP、吞吐、QUIC、游戏或所有 UDP 业务可用；DNS 响应也不是经过 DNSSEC 验证的内容真实性保证。

## 来源、凭据与回退

远端规则只保存方案 ID、节点 ID、节点参数摘要和公开验收目标。凭据留在控制端既有加密方案内，普通控件和审阅只显示来源名称与目标；不会把代理密码写入远端转发配置或转发器启动参数。

审阅固定方案文件摘要。执行前核对节点身份、受管来源与实际目标；验收后再次确认来源没有变化，结果绑定节点摘要、UDP 传输、DNS 目标及查询参数。缺少这些证据、凭据错误、响应不匹配、来源变化或取消，均不允许提交。沿用第九轮的组件范围事务；只恢复 UDP 转发及本次受管防火墙，不触及 TCP 转发、其他代理、SSH 或监控，远端回复不明不重放写操作。

## 本地证据

- 完整 .NET 回归 1732 项断言通过，包含第八、九轮边界与新增来源、证据和回退分支。未配置的真实 Xray 分支另用现有固定资产补测；具体运行结果见本版[发行记录](TESTING-0.9.35.zh-CN.md)。
- 固定 sing-box 真实 UDP 回环覆盖六种方法、A／AAAA、两种 SS2022 AES 多用户身份链及 IPv6 转发入口。错误密码、阻断转发、取消和临时配置清理均验证；没有生产连接。
- WinUI 隐藏原生表单覆盖来源选择、参数回填、非法参数保留、无凭据显示、实际审阅和取消。测试不激活窗口、不操作鼠标，不安装应用。
- 本机隐藏窗口滚动后，对该滚动子区域的额外位图渲染返回 `E_INVALIDARG`。这项截图调用已移除，保留首屏截图及真实滚动位置、来源选择、保存回填和取消断言，不修改业务界面来迎合截图工具。测试失败另保留不含输入值的类型、堆栈和阶段记录。
- Linux 转发回环在 WSL 的临时用户／网络命名空间执行。普通镜像网络的 IPv4 回环测试出现超时，未将其当作通过；隔离网络中 UDP 21 项和 TCP 18 项通过，UDP 因缺少非回环接口跳过的一项另用命名空间内虚拟接口补测通过。现用 WSL 网络、代理及配置不变。

这些结果不等于 Debian 12／13 整机安装、真实防火墙调度、服务商安全组或公网业务验收。GitHub 检查以本次发行提交为准。
